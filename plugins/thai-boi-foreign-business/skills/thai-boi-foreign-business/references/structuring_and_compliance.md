# structuring_and_compliance.md — โครงสร้างผู้ถือหุ้นและการควบคุมโครงการ

อ่านไฟล์นี้เมื่อเลือกโครงสร้างบริษัทเทคโนโลยีที่ก่อตั้งโดยต่างชาติ ทำข้อตกลงผู้ถือหุ้น หรือเตรียมรับตรวจ

ข้อมูล ณ 9 ตุลาคม 2569 (2026) กฎหมายเป็น **(สรุปสาระ)**; การควบคุมเอกสารเป็นข้อเสนอปฏิบัติ ไม่ใช่เงื่อนไขกฎหมายเพิ่ม รหัส/URL ใน `key_sections.md`

---

## สารบัญ
1. ผังเลือกเส้นทาง
2. ธรรมาภิบาลและผู้ถือหุ้น
3. กิจกรรม รายได้และ IP
4. ปฏิทินและหลักฐาน
5. รับตรวจและแก้ช่องว่าง

## 1. ผังเลือกเส้นทาง

```text
กิจกรรมจริงทุกสาย → ต่างด้าวตาม FBA ม.4?
ไม่ใช่ → เงินทุนไทยจริง/นอมินี/กฎหมายเฉพาะ/คนทำงาน
ใช่ → บัญชีใด?
  ไม่อยู่/ยกเว้น → เก็บฐาน; ตรวจทุนและกฎหมายเฉพาะ
  บัญชีหนึ่ง → ห้ามฐานทั่วไป; BOI ม.12 ไม่เป็นทางลัด
  สอง/สาม → ฐานอื่น?
    BOI/IEAT → ขอบเขตบัตร/อนุญาต + แจ้ง FBC ม.12
    สนธิสัญญา → สัญชาติ/ควบคุม + FBC ม.10/11
    ไม่มี → FBL ม.17/เกณฑ์เฉพาะ
ทุกเส้นทาง → แยกสิทธิบริษัท / อยู่ / ทำงาน / ภาษี
```

(สรุปสาระ) ม.4 ทุนตั้งแต่กึ่งหนึ่งเป็นต่างด้าว; ไทยส่วนใหญ่ต้องร่วมลงทุนจริงไม่ถือแทน ม.36 [F1]

| ทางเลือก | เหมาะเมื่อ/เงื่อนไขที่ต้องประเมิน |
|---|---|
| ไทยส่วนใหญ่จริง | หุ้นส่วนลงทุน/เสี่ยง/ผลประโยชน์จริง; ไม่รับประกันควบคุมต่างชาติ; คำสั่งทุน DBD 2/2569 |
| BOI+FBC | งาน/ทีมเข้าเกณฑ์; เฉพาะบัตร; ภาระเปิด/รายงาน; ภาษีไม่ครบทุกสาย |
| FBL | งานจำกัดไม่เข้า BOI/ยกเว้น; ประโยชน์ไทย ม.5 ทุน/เงื่อนไข; ไม่รับประกันอนุมัติ |
| สนธิสัญญา+FBC | สัญชาติ/ควบคุมจริง; กิจกรรมสงวนและรักษาคุณสมบัติหลังเพิ่มทุน |
| บริการยกเว้น | ผู้รับ/สัมพันธ์/เนื้องานตรงกฎ; กลุ่มไม่ขยายตลาดภายนอก |

เสนอเงื่อนไขก่อนเริ่ม การควบคุม เอกสาร/ต้นทุน ไม่เสนอ 49/51 เป็นสูตรเลี่ยงหรือแยกบริษัทเปลี่ยนชื่อกิจกรรมโดยผู้ทำจริงไม่เปลี่ยน [F1, F3, F6]

## 2. ธรรมาภิบาลและผู้ถือหุ้น

ส่งสัญญา `thai-contract-master`; มติ/ทะเบียน `thai-corporate-secretarial` พร้อมข้อจำกัดใบอนุญาต ไม่ร่างให้ฝ่ายไทยไม่มีผลประโยชน์จริง

| ประเด็น | คำถามส่งต่อ |
|---|---|
| เงิน/ผู้ได้ประโยชน์ | ใครจ่าย บัญชีใด หนี้/คืนเงิน กำไรและความเสี่ยงจริง? |
| กรรมการ/ลงนาม | หน้าที่ สิทธิทำงาน แต่งตั้ง/ขัดผลประโยชน์/ผู้ต้องแจ้ง? |
| Reserved matters | คุ้มครองลงทุนอย่างไร ผลรวมสิทธิออกเสียง/กำไร? veto ไม่ผิดหรือปลอดภัยทุกแบบ |
| เพิ่มทุน/โอน/VC | ต่างด้าว/สนธิสัญญา/บัตรก่อน closing? ไม่แก้หุ้นแล้วเริ่มงานจำกัดทันที |
| IP/กลุ่ม | ใช้ พัฒนา อนุญาตช่วง ขาย รับเงินและราคาตรงคำขอ? IP ส่ง `thai-copyright-software` ภาษี `thai-tax-international` |
| เลิก/ผิดนัด | แจ้ง BOI/DBD/DOE/ตม./ภาษี? ไม่รับรองใบอนุญาตโอนเอง |

**Red flags:** คนไทยไม่รู้กิจการ/ไม่มีเงิน จ่ายวนคืน รับค่าชื่อ ลงชื่อเปล่า ผู้จัดตั้งจัดคนให้ครบเปอร์เซ็นต์ หยุดใช้โครงสร้าง ขอที่มาเงิน/ทางเลือกจริง ไม่สร้างหลักฐานย้อนหลัง [F1, F6–F8]

## 3. กิจกรรม รายได้และ IP

ใช้ตารางเดียวเทียบ BOI/FBC สัญญา ใบแจ้งหนี้ บัญชีและภาษี:

| กิจกรรม | หลักฐาน/การตัดสินใจ |
|---|---|
| พัฒนาในไทย | ทีม/รุ่นก่อน–หลัง/งาน/ค่าใช้จ่าย → ตรงบัตร? |
| Licence/Subscription ต่างประเทศ | chain of rights/รุ่น/สัญญา/ปี → ผลงานโครงการ ป.12/2566 ข้อ 5 ไม่ใช้ประเทศลูกค้า |
| ตัวแทน/commission | ผู้ทำ/ขายจริง/ส่วนแบ่ง → ไม่เปลี่ยนชื่อเป็น royalty |
| ขายต่อ/ฮาร์ดแวร์ | สัญญาซื้อ/ตัวแทน/รายรับ → แยกบัตรพัฒนา/ภาษี/FBA |
| บริการกลุ่ม | ผู้รับ/สัมพันธ์/งาน → นิยามแต่ละบริการต่างกัน |

(สรุปสาระ) ไม่พบกฎทั่วไปต้องถือ IP ทั้งหมด ต้องพิสูจน์ **งานในโครงการและสิทธิหารายได้** ไม่สรุป IP ต่างประเทศได้/ไม่ได้ทันที ค่าทีมต่างประเทศไม่แทนเกณฑ์ IT ไทย หารือ BOI เป็นหนังสือตามโครงสร้างจริง [B4–B5]

## 4. ปฏิทินและหลักฐาน

แยกวันกฎหมาย/บัตรจากวันเตือนภายใน ใช้ `templates.md`:

- BOI: รับมติ ตอบรับ บัตร เปิด รายได้แรก รายไตรมาส/ปี/e-Tax [B1–B2, B13–B15]
- DBD: ขอบเขต/อายุฐาน FBL/FBC เงินเข้า ย้าย/เลิก/ใบแทน สัญชาติและเงื่อนไข [F1, F4]
- คนทำงาน: ตำแหน่ง/บรรจุ สิทธิอยู่/ทำงาน เข้า/เปลี่ยน/ออก/ข้อยกเว้น รายงานวีซ่า [W1, W6, V1–V5]
- เปลี่ยนโครงการ: BOI+DBD+สัญญา/IP+ภาษี+บุคลากร ไม่ปิดเพียงหน่วยงานเดียว

ทะเบียนหลักฐาน: บัตร/ใบอนุญาต/แนบท้ายทุกฉบับ หุ้น/ทุน/ธนาคาร คำขอที่ส่งจริง สัญญา/ใบแจ้งหนี้ ผลงาน/ค่าใช้จ่าย/บุคลากร บัญชีแยก หนังสือส่ง/รับ/ขยาย บันทึกใช้สิทธิ พร้อมเจ้าของ/สิทธิเข้าถึง จำกัดสำเนาหนังสือเดินทาง/statement เท่าที่จำเป็น PDPA ส่ง `thai-pdpa`

## 5. รับตรวจและแก้ช่องว่าง

(สรุปสาระ) BOI IPA ม.14/15; DBD FBA ม.30/40 มีเงื่อนไขเรียก/เข้าตรวจ/ผลไม่ตอบ [B1, F1] ตรวจอำนาจ/หนังสือ/วันตอบ → ผู้ประสาน → รักษาต้นฉบับ → รวบรวมจริง → ทนายตรวจ → ส่ง/เก็บใบรับ ห้ามลบ/เปลี่ยนชื่อ/ย้อนหลังให้ตรงคำขอ

| ระดับ | ช่องว่าง → หลักฐานปิด |
|---|---|
| สูง | นอก FBC/ทำงานไม่มีสิทธิ/ถือแทน → หยุดส่วนผิด ทนาย/ฐานสิทธิจริง ไม่ใช่สัญญาว่าจะได้ |
| ปานกลาง | ใกล้ครบ/บัตรไม่ตรง → ส่ง/แก้ ใบรับ/อนุมัติ |
| ต่ำ | หลายรุ่น/เจ้าของไม่ชัด → ทะเบียน/ผู้รับผิดชอบ |
| ต้องตรวจ | IP/ชั่วคราว/ประเภทคลุมเครือ → คำตอบหน่วยงาน/ข้อสงวนก่อนเริ่ม |

พัก/เพิกถอนเก็บวันรับแจ้ง ส่ง `thai-litigation-deadlines`/`thai-legal-opinion` ทันที หารือ/อุทธรณ์ไม่หยุดเวลา/ทุเลาทุกกรณี ผลภาษีส่ง `thai-tax-international`

## หลักการ
- โครงสร้างตรงงานและเงินจริง ไม่ซ่อนผู้ถือหุ้น
- ทุกเอกสารเล่าเรื่องเดียวกัน ไม่ให้หน่วยงานเห็นคนละธุรกิจ
- ช่องว่างมีเจ้าของ กำหนดและหลักฐานปิดตามผลกระทบ
- สิทธิบริษัทไม่ให้สิทธิทำงาน และสิทธิทำงานไม่อนุญาตธุรกิจ
