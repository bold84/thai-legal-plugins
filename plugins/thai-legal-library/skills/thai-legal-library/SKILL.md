# thai-legal-library — คลังกฎหมายไทย

## วัตถุประสงค์

เป็น **คลังตัวบทกฎหมายไทย** กลางที่ปลั๊กอินงานทนายความตัวอื่น ๆ (เช่น `thai-litigation-pleadings`, `thai-legal-opinion`, `thai-compliance-audit`) เรียกใช้เพื่ออ้างมาตรา/บทบัญญัติ/หลักกฎหมายอย่างถูกต้อง โดยไม่ต้อง bundle ตัวบทกฎหมายเข้าทุกปลั๊กอิน

## เมื่อไรให้ใช้สกิลนี้

- เมื่อปลั๊กอินอื่นต้องอ้างมาตราในประมวลหรือ พ.ร.บ. ของไทย
- เมื่อต้องค้นหาตัวบทใดอยู่หมวดใด → เปิด `references/big_data_md/00_INDEX.md`
- เมื่อจะตรวจคุณภาพของไฟล์ในคลัง → เปิด `references/big_data_md/_QUALITY_REPORT.md`
- เมื่อต้องการรายการเลขฎีกาบรรทัดฐานที่ต้องตรวจสอบก่อนใช้ → เปิด section 3 ของ `_QUALITY_REPORT.md`
- เมื่อต้องการรายการเลขมาตราที่อ้างในไฟล์ B/C → เปิด section 4.1 ของ `_QUALITY_REPORT.md`

> **หมายเหตุ:** สกิลนี้คู่กับ `thai-legal-forms` ที่บรรจุแบบพิมพ์ศาล 192 ไฟล์ใน 15 กลุ่ม — ถ้าต้องใช้แบบฟอร์ม ลงปลั๊กอินนั้นด้วย

## เส้นทางใช้งานจริง

ใน Claude Code เปิด `${CLAUDE_SKILL_DIR}/references/big_data_md/00_INDEX.md` โดย
`${CLAUDE_SKILL_DIR}` เป็นฐานของสกิลคลังนี้ ไม่ใช่ฐานของปลั๊กอินงานที่เรียกมา หากระบบยังแสดง
ตัวแปรตามตัวอักษร ให้ใช้ฐานไดเรกทอรีที่ระบบแจ้งเมื่อโหลดสกิลแทน ห้ามเดาจาก working directory
หรือโฟลเดอร์ข้างเคียง เพราะปลั๊กอินแต่ละตัวอาจติดตั้งอยู่คนละแคชและคนละเวอร์ชัน

เส้นทาง `references/big_data_md/` ในสกิลงานและเอกสารอ้างอิงของชุดนี้ต้องอ่านจากฐานสกิลคลังนี้
เสมอ ไม่ใช่จากฐานสกิลงาน หากไม่พบคลังให้แจ้งข้อจำกัดและค้นตัวบทจากแหล่งทางการแทน ห้ามอ้าง
ว่าได้อ่านไฟล์ในคลังแล้ว

## หลักการสำคัญ

1. **ใช้ 00_INDEX.md เป็นจุดเริ่มต้นเสมอ** — ระบุไฟล์ที่ต้องเปิด ระดับคุณภาพ (A/B/C) และปลั๊กอินที่จะใช้
2. **เคารพนโยบาย 3 ชั้น** — ระดับ A อ้างได้ตรง · ระดับ B/C ใช้เป็นไกด์ค้น · ฎีกาต้องตรวจกับ "สืบค้นฎีกา 2015" ก่อนอ้าง
3. **ห้ามแก้ไขเนื้อหาตัวบท** — เป็น read-only reference; การอัปเดตทำผ่านการแพ็กปลั๊กอินรุ่นใหม่
4. **ตรวจฉบับแก้ไขล่าสุดก่อนใช้** — ตัวบทในคลังอาจตามฉบับแก้ไขไม่ทันถ้ามีการแก้ไขใหม่หลังวันที่แพ็ก

## ข้อห้ามเด็ดขาด

❌ ห้ามแก้ไขเนื้อหาในไฟล์ของคลัง — ใช้เป็น read-only reference เท่านั้น
❌ ห้ามประดิษฐ์เลขมาตรา/ฎีกา หรือข้อกฎหมายที่ไม่มีอยู่จริง — ถ้าคลังไม่มี ให้ระบุชัดเจนว่า "ไม่พบในคลัง" และให้ตรวจกับฉบับปัจจุบัน
❌ ห้ามอ้างเลขฎีกาจาก 05_dika หรือ 07_practical ลงในคำคู่ความโดยไม่ตรวจกับระบบสืบค้นฎีกาของศาลฎีกาก่อน (โดยเฉพาะปี 2566+)
❌ ห้ามตีความว่าคลังเป็น "ทางการ" — ตัวบทจริงต้องตรวจกับ http://www.krisdika.go.th หรือราชกิจจานุเบกษา

## ตัวบทที่ยังไม่มีในคลัง (ณ 9 ตุลาคม 2569)

กฎหมายต่อไปนี้ยังไม่อยู่ใน `big_data_md/` — ห้ามอ้างว่ามีในคลัง ปลั๊กอินที่ใช้กฎหมายเหล่านี้สรุป
มาตราสำคัญพร้อมลิงก์แหล่งทางการไว้ใน `references/key_sections.md` ของปลั๊กอินนั้น (สถานะเทียบเท่า
ระดับ B จนกว่าจะตรวจกับตัวบทจริงที่ krisdika.go.th หรือราชกิจจานุเบกษา):

- พ.ร.บ.ลิขสิทธิ์ · พ.ร.บ.สิทธิบัตร · พ.ร.บ.เครื่องหมายการค้า · พ.ร.บ.ความลับทางการค้า
- พ.ร.บ.ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ · พ.ร.บ.การรักษาความมั่นคงปลอดภัยไซเบอร์ · พ.ร.ฎ.การประกอบธุรกิจบริการแพลตฟอร์มดิจิทัลที่ต้องแจ้งให้ทราบ · พ.ร.ก.มาตรการป้องกันและปราบปรามอาชญากรรมทางเทคโนโลยี
- พ.ร.บ.ส่งเสริมการลงทุน · พ.ร.บ.การประกอบธุรกิจของคนต่างด้าว · พ.ร.ก.การบริหารจัดการการทำงานของคนต่างด้าว
- พ.ร.บ.ว่าด้วยการขัดกันแห่งกฎหมาย · พ.ร.บ.ขายตรงและตลาดแบบตรง · พ.ร.บ.ว่าด้วยราคาสินค้าและบริการ · พ.ร.บ.การแข่งขันทางการค้า
- พ.ร.บ.การควบคุมสินค้าที่เกี่ยวข้องกับการแพร่ขยายอาวุธที่มีอานุภาพทำลายล้างสูง · อนุสัญญาภาษีซ้อน
- ประกาศของคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล กระทรวงดิจิทัลฯ ETDA สกมช. กรมสรรพากร BOI และกระทรวงพาณิชย์
