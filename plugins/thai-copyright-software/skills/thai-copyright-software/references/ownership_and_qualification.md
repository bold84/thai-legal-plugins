# ownership_and_qualification.md — งานที่คุ้มครอง เจ้าของ อายุ และ AI

อ่านไฟล์นี้เมื่อระบุงาน คุณสมบัติ เจ้าของแรก อายุ หรือโค้ดที่ใช้ AI ข้อมูล ณ 9 ตุลาคม 2569 (2026) กฎหมายเป็น **(สรุปสาระ)**; การประยุกต์แยกเป็นการตีความ แหล่งหลัก: [DIP ฉบับรวม](https://ipthailand.go.th/images/3534/2565/Copyright/Copyright_Act2_TH.pdf); แหล่งอื่นใน `key_sections.md`

## 1. งานที่คุ้มครอง/ไม่คุ้มครอง

**ม.4, 6:** วรรณกรรมรวมโปรแกรม นาฏกรรม ศิลปกรรม ดนตรีกรรม โสตทัศนวัสดุ ภาพยนตร์ สิ่งบันทึกเสียง แพร่เสียงแพร่ภาพ และงานอื่นในแผนกวรรณคดี วิทยาศาสตร์หรือศิลปะ โปรแกรมคือคำสั่ง/ชุดคำสั่ง/สิ่งอื่นที่ใช้กับคอมพิวเตอร์ให้ทำงานหรือได้ผล ไม่จำกัดภาษา

**ม.11–13:** ดัดแปลงโดยได้รับอนุญาตมีสิทธิในส่วนใหม่ ไม่กระทบสิทธิเดิม; รวบรวมงานโดยได้รับอนุญาต หรือข้อมูล/สิ่งอื่นด้วยการคัดเลือกหรือจัดลำดับที่มิได้ลอกเลียน อาจคุ้มครอง ม.12; ม.8–10 ใช้โดยอนุโลม ไม่ทำให้ข้อมูลดิบมีสิทธิผูกขาด ไม่พบบทสิทธิฐานข้อมูลเฉพาะ (sui generis) ในฉบับที่ตรวจ

**ม.6 วรรคสอง:** ไม่คุ้มครองความคิด ขั้นตอน กรรมวิธี ระบบ วิธีใช้/ทำงาน แนวความคิด หลักการ การค้นพบ ทฤษฎีวิทยาศาสตร์/คณิตศาสตร์ โค้ดที่แสดงออกอาจคุ้มครองต่างหาก ไม่ใช่อนุญาตให้คัดโค้ด/API; ยังไม่ยืนยันแนวศาลไทยเรื่อง API/ความคล้ายเชิงโครงสร้าง

**ม.7:** ไม่คุ้มครองข่าว/ข้อเท็จจริงที่เพียงข่าวสาร กฎหมาย ระเบียบ/ประกาศ/คำสั่ง/หนังสือรัฐ คำพิพากษา/คำวินิจฉัย/รายงานราชการ และคำแปล/รวบรวมรายการดังกล่าวโดยรัฐ ต่างจาก **ม.14** ที่รัฐถือสิทธิซอฟต์แวร์ได้

**แนวปฏิบัติ:** แยกโค้ด เอกสาร UI/ไอคอน ภาพ เสียง วิดีโอและชุดข้อมูล; fork ตรวจสิทธิเดิมและส่วนเพิ่ม ฐานอื่น → `thai-patent`, `thai-trademark`, `thai-pdpa`, `trade_secrets.md`

## 2. คุณสมบัติและต่างประเทศ

**ม.8:** ไม่ต้องจดทะเบียน แต่ต้องเข้าเงื่อนไข:
- ยังไม่โฆษณา: สัญชาติ/การอยู่ไทยหรือประเทศภาคีที่ไทยร่วมเป็นภาคี ตามเงื่อนไขตลอดหรือส่วนใหญ่ของช่วงสร้างในมาตรา
- โฆษณาแล้ว: ครั้งแรกในไทย/ภาคี หรือในไทย/ภาคีภายใน 30 วันหลังครั้งแรกนอกประเทศดังกล่าว หรือผู้สร้างเข้า ม.8(1) ขณะโฆษณาครั้งแรก
- ฐานสัญชาติไทยของผู้สร้างนิติบุคคลต้องจัดตั้งตามกฎหมายไทย

**ม.4, 24:** โฆษณา (publication) มีนิยามเฉพาะการนำสำเนาที่ทำโดยยินยอมออกจำหน่ายจำนวนพอสมควร; เผยแพร่ไม่ใช่โฆษณาทุกแบบ การเริ่มนับอายุต้องยินยอมเจ้าของ ไม่ใช้ที่ตั้งเซิร์ฟเวอร์/วัน commit แทนประเทศ/วันโฆษณา release ออนไลน์ต้องวิเคราะห์จริง

**ม.61:** งานประเทศภาคีที่ไทยร่วมเป็นภาคี/องค์การระหว่างประเทศที่ไทยเป็นสมาชิกได้รับคุ้มครอง ตรวจบัญชีลง 8 พฤศจิกายน 2567 แทนบัญชี 2559 และ [WIPO](https://www.wipo.int/wipolex/en/members/profile/TH): Berne มีผลกับไทย 17 กรกฎาคม 2474; TRIPS 1 มกราคม 2538; WCT 13 ตุลาคม 2565; Marrakesh 28 เมษายน 2562 วัน WCT ไม่ใช่วันใช้ฉบับที่ 5 (23 สิงหาคม 2565) ไม่พบชื่อไทยในบัญชี WPPT/Rome ที่ตรวจ

ม.8, 61 ตอบการคุ้มครองในไทย ไม่ชี้เจ้าของแรกตามกฎหมายถิ่นทุกเรื่อง → `thai-international-disputes`

## 3. เจ้าของแรก

| สถานะจริง | ฐานเริ่มต้น/เอกสาร |
|---|---|
| ผู้ก่อตั้งก่อนมีบริษัท | ม.8 ผู้สร้างถือสิทธิเมื่อเข้าเงื่อนไข; โอน ม.17 หลังตั้งบริษัท ไม่เกิดสิทธิย้อนหลัง |
| ลูกจ้าง | ม.9 ผู้สร้างถือสิทธิ เว้นแต่ตกลงเป็นหนังสือ; นายจ้างเผยแพร่ตามวัตถุประสงค์จ้าง ตรวจข้อตกลงวันสร้าง |
| ผู้รับจ้างสร้างงาน | ม.10 ผู้ว่าจ้างถือสิทธิเว้นแต่ตกลงอื่น แยกวัสดุเดิม/จ้างช่วง |
| ฝึกงาน/นักศึกษา/อาสาสมัคร | ตรวจความสัมพันธ์จริง สถาบัน นายจ้างอื่น ผู้เยาว์ ไม่ตัดสินจากชื่อตำแหน่ง |
| หน่วยงานรัฐจ้าง/สั่ง/ควบคุม | ม.14 หน่วยงานถือสิทธิ เว้นแต่ตกลงอื่นเป็นหนังสือ |
| ดัดแปลง/รวบรวม | ม.11–13 สิทธิส่วนใหม่ไม่ล้างสิทธิเดิม |
| ผู้ร่วมสร้าง | ม.19 วรรคสองกำหนดอายุ ไม่กำหนดบริหารสิทธิร่วม ทำข้อตกลงทุกเจ้าของ |
| ผู้เขียนต่างประเทศ | ม.8, 61 + กฎหมายถิ่น ขอเอกสารเจ้าของจริงด้วย |
| บอท/CI/AI | ตามโค้ดมนุษย์ต้นทาง generator และส่วนเครื่องสร้างใหม่ |

ป.พ.พ. ม.575, 587 แยกจ้างแรงงาน/จ้างทำของ ชื่อ contractor ไม่ชี้ขาด **ม.10 ไม่กำหนดให้ข้อตกลงอื่นต้องเป็นหนังสือ** ต่างจาก ม.9, 14 แต่การโอนสิทธิที่มีแล้วต้องครบ ม.17 ซื้อ SaaS/โปรแกรมสำเร็จรูปไม่ใช่จ้างสร้างงานเสมอ

**การตีความ:** สิทธิเผยแพร่ของนายจ้าง ม.9 ไม่ใช่ทุกสิทธิ ม.15; ไม่สันนิษฐาน licence โดยปริยาย งานร่วมอาจเทียบ ป.พ.พ. ม.1357, 1361 ต้องตรวจแนววินิจฉัย ไม่ใช้เสียงข้างมาก relicense ส่วนทุกคน

| ทุกผู้สร้างตายก่อนโฆษณา | ม.19 วรรคสาม 50 ปีจากโฆษณาครั้งแรก |

| ศิลปประยุกต์ | ม.22 25 ปีจากสร้าง/โฆษณาครั้งแรกในช่วงนั้น |
| งานรัฐ ม.14 | ม.23 50 ปีจากสร้าง/โฆษณาครั้งแรกในช่วงนั้น |

## 5. AI และข้อมูลฝึก

**ข้อยุติที่ยังไม่มี:** ม.4, 6 ไม่ระบุว่า prompt/เลือก/แก้เท่าใดเป็นผู้สร้าง ในแหล่งทางการที่เข้าถึงรอบนี้ **ไม่พบคำพิพากษาไทย/คำวินิจฉัย DIP ยืนยันลิขสิทธิ์โค้ด AI ล้วนหรือเกณฑ์ human authorship เฉพาะ** ต้องตรวจสอบกับฉบับปัจจุบัน ไม่ใช้กฎหมายสหรัฐฯ/EU แทนไทย

[แบบ ลข.01 DIP](https://webnew.ipthailand.go.th/wp-content/uploads/2026/02/cpr-pdf-01.pdf) ถาม Generative AI และส่วนที่ใช้ ไม่รับรองว่าเครื่องเป็นผู้สร้าง การรับแจ้งไม่รับรองลิขสิทธิ์

**แนวปฏิบัติ:** AI ล้วนไม่รับรองสิทธิเจ้าของบัญชี; terms ไม่ก่อสิทธิตามกฎหมายเอง AI ช่วยมนุษย์เก็บต้นฉบับ/diff ส่วนเลือก/เรียบเรียง/แก้โดยมนุษย์ และตรวจโค้ดผู้อื่น review บั๊กอย่างเดียวไม่พิสูจน์สร้างงานใหม่ บอท commit ไม่ทำให้โค้ดเป็น public domain

**ข้อมูลฝึก:** ฉบับรวมถึงฉบับที่ 5 **ไม่พบบทยกเว้นเฉพาะ TDM/ฝึก AI** ไม่เท่ากับการฝึกทุกกรณีผิด แยกเข้าถึง/สำเนา/รวบรวม/ฝึก/เผยแพร่: โปรแกรม ม.30, 35 งานอื่น ม.27, 32 งานรวบรวม ม.12 RMI/TPM ม.53/1–53/8 ตรวจ licence วัตถุประสงค์และผลตลาด ฝึกบริการเชิงพาณิชย์ไม่เป็นไม่แสวงกำไรเพราะขั้นฝึกไม่มีรายรับ → `thai-ai-governance`, `thai-pdpa`

## 6. ผังตรวจ

```text
งาน/เวอร์ชัน → ม.4, 6, 7 → ผู้สร้างจริง/มนุษย์ต้นทาง
→ ม.8, 61: สัญชาติ ถิ่นที่อยู่ ช่วงสร้าง ประเทศ/วันโฆษณา
→ ม.9–14: เจ้าของแรก → ม.17, 18: โอน/ศีลธรรม
→ ม.19–26: อายุ → OSS/AI/กฎหมายถิ่น → manifest
```

เก็บข้อตกลงที่มีผลวันสร้าง release licence และข้อพิสูจน์ไม่ได้ใน `templates.md` ข้อ 8; ตรวจต่อ `software_chain_of_title.md` การถือ repository ไม่พิสูจน์เจ้าของ

## หลักการ
- ตรวจงาน คุณสมบัติ เจ้าของ ก่อนการโอน
- ไม่ใช้ work-for-hire ต่างประเทศหรืออายุของผู้รับโอน
- AI/TDM แยกตัวบท ข้อเท็จจริง และการตีความ
- ปิดท้ายด้วย "ข้อสังเกตจากทนาย"
