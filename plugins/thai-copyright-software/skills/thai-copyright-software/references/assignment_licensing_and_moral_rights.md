## 1. สิทธิแต่ผู้เดียว

ม.15(1) ทำซ้ำ/ดัดแปลง (2) เผยแพร่ (3) **ให้เช่าต้นฉบับ/สำเนาโปรแกรม** รวมโสตทัศนวัสดุ ภาพยนตร์ บันทึกเสียง (4) ให้ประโยชน์ผู้อื่น (5) อนุญาต (1)–(3)

ไม่มีสิทธิ “ใช้” แยกในรายการ; การติดตั้ง/รันอาจเกี่ยวกับทำซ้ำ ม.4 ต้องตรวจอนุญาต/ม.35(2)(5)(8)/ม.32/2 รายกรณี SaaS เขียนสิทธิ host/ให้บริการชัด ม.32/1 ขายสำเนาที่ได้กรรมสิทธิ์โดยชอบ ไม่ครอบคลุมให้เช่าตาม ม.15(3)

## 2. licence

ม.15(5) กำหนดเงื่อนไขได้แต่ห้ามจำกัดการแข่งขันโดยไม่เป็นธรรม เกณฑ์กฎกระทรวง 2540 ตรวจ `key_sections.md` ไม่สรุปทุกข้อว่าโมฆะโดยอัตโนมัติ ม.16 อนุญาตแล้วไม่ตัดสิทธิให้ผู้อื่น **เว้นหนังสือระบุห้าม** ผูกขาดเขียนชัด รวมเจ้าของใช้เองได้หรือไม่

กฎหมายนี้ไม่กำหนดแบบ licence เช่นโอน แต่ควรทำหนังสือ ระบุสิทธิ/ดินแดน/เวลา/สาขา ผู้ใช้ ซอร์ส/ออบเจกต์ ช่วงสิทธิ งานปรับปรุง escrow ค่าตอบแทน เหตุเลิก/หลังเลิก ความลับ audit และชดใช้ IP → ข้อสัญญาทั่วไป `thai-contract-master`; ภาษี `thai-tax-international`

ใช้เกินอนุญาตอาจเข้า ม.27, 30; แยกเงื่อนไขขอบเขตสิทธิจากข้อผูกพัน ไม่ใช่ผิดสัญญาทุกข้อเป็นละเมิด สิทธิฟ้องผู้รับอนุญาตผูกขาดยังไม่ยืนยันแนวศาลไทย ไม่ถือว่ามีอำนาจฟ้องเจ้าของเสมอ → ทนายคดีตรวจฐาน/โจทก์/มอบอำนาจ ข้อพิพาท licence ศาลฯ ม.7(3); อนุญาโตตุลาการ ม.7(11) → `thai-international-disputes` OSS ดู `software_chain_of_title.md` ข้อ 5

## 3. โอน ม.17

ทั้งหมด/บางส่วน จำกัดเวลาหรือตลอดอายุ การโอนมิใช่มรดก **หนังสือลงนามผู้โอนและผู้รับโอน** ไม่ระบุเวลา = **สิบปี** ไม่ใช่ค่าเริ่มต้นตลอดไป ขาดแบบเสี่ยงโมฆะ ป.พ.พ. ม.152

เอกสารที่โมฆะเพราะขาดแบบไม่ฟื้นด้วยสัตยาบัน (ป.พ.พ. ม.172) ให้โอนใหม่วันที่จริงและอนุญาต/ตกลงข้อเรียกร้องการใช้เดิมแยก; ม.177 เป็นสัตยาบันโมฆียะกรรม ไม่ใช่โมฆะกรรม ไม่สันนิษฐาน licence โดยปริยาย ครบสิบปีตรวจสิทธิ/โอนใหม่ ระบุ “ตลอดอายุแห่งการคุ้มครองลิขสิทธิ์” ตาม ม.19–23

ตัวบทโอน “บางส่วน” แต่ไม่กำหนดดินแดนละเอียด การแบ่งประเทศ/สาขาต้องตรวจวิธีแบ่งสิทธิและกฎหมายถิ่น ไม่ถือว่าทั่วโลกได้ผลเพียงเขียนถ้อยคำไทย

## 4. ประเด็นร่าง

| ประเด็น | แนวปฏิบัติ/ฐาน |
|---|---|
| งาน/แบบ | ภาคผนวก repo/commit/เวอร์ชัน/ไฟล์ ข้อยกเว้นวัสดุเดิมและ OSS; ลงนามสองฝ่าย อายุครบ |
| งานอนาคต | ม.8, 17 ไม่รับรองผลโอนสิทธิยังไม่เกิดชัด → โอนสิทธิที่มีปัจจุบัน + ตกลงโอนเมื่อเกิดงานเท่าที่บังคับได้ + licence สำรอง + ยืนยันรายงวด |
| ความสามารถ | ป.พ.พ. ม.19–20 บรรลุนิติภาวะ 20 ปี/สมรสตามเงื่อนไข; ม.21 ขาดยินยอมอาจโมฆียะ ม.22 ไม่สมมติการโอนเป็นข้อยกเว้น; ตรวจผู้แทน/สัตยาบัน ม.177 |
| สิทธิเรียกร้องเดิม | ระบุเฉพาะสิทธิที่โอนได้ ป.พ.พ. ม.306 หนังสือโอน และบอกกล่าว/ยินยอมเป็นหนังสือจึงยกต่อลูกหนี้/บุคคลภายนอก; ม.307 ลำดับสิทธิ; พ.ร.บ.ลิขสิทธิ์ฯ ม.63 อายุความ ไม่ถือว่าโอนอำนาจร้องทุกข์อาญาเอง |
| กรรมการ/ผู้ถือหุ้น | ป.พ.พ. ม.805 ทำกับตนเองต้องยินยอมตัวการ; ม.1168 หน้าที่กรรมการ; ม.1185 ห้ามผู้ถือหุ้นที่มีส่วนได้เสียพิเศษออกเสียงมตินั้นในที่ประชุมใหญ่ ไม่ใช่กฎออกเสียงกรรมการ → `thai-corporate-secretarial` |
| ค่าตอบแทนเล็กน้อย/ให้เปล่า | ไม่ตั้งราคาสำเร็จรูป; ภาษีในประเทศ → `thai-tax-revenue-code`; มูลค่า/ข้ามพรมแดน/รายการเกี่ยวข้อง → `thai-tax-international`, `thai-corporate-secretarial` |
| e-signature | พ.ร.บ.ธุรกรรมฯ ม.8 เข้าถึง/นำกลับโดยความหมายคงเดิม; ม.9 ตัวตน เจตนา ความเชื่อถือตามเงื่อนไข เก็บหลักฐานสองฝ่าย → `thai-tech-platform-law` |
| ต่างประเทศ | แบบ/เจ้าของแรก/สิทธิที่สละไม่ได้ตามกฎหมายถิ่น → `thai-international-disputes` |

**งานอนาคต:** licence สำรองระบุแต่ผู้เดียว รวมสิทธิใช้เองของผู้ให้ สิทธิทำซ้ำ/ดัดแปลง/เผยแพร่/ให้เช่า ช่วงสิทธิ ทั่วโลกเท่าที่บังคับได้ ตลอดอายุ ไม่มีค่าตอบแทนเพิ่มและไม่เพิกถอน **เท่าที่กฎหมายอนุญาต** ไม่แก้ปัญหาที่ผู้ให้ไม่มีสิทธิ มีคู่แข่ง/นายจ้างเดิมหรือ ม.15(5) ติดขัด รับรองตอนส่งมอบและลงหนังสือยืนยันเพิ่มเติม พร้อม further assurance ที่มีขอบเขตและค่าใช้จ่าย

**POA สำรอง:** ป.พ.พ. ม.798 หากนิติกรรมต้องเป็นหนังสือ ตัวแทนต้องตั้งเป็นหนังสือ; ลงสองฝั่งเข้าข้อ ม.805 ต้องยินยอมตัวการ ใช้ผู้โอนลงเองเป็นหลัก จำกัดอำนาจเฉพาะงาน ห้ามเพิ่มคำรับรอง/ค่าตอบแทนฝ่ายเดียว ไม่รับรองว่าเพิกถอนไม่ได้หรืออยู่หลังตายเสมอ → `thai-contract-master`

**ก่อนปิดดีล:** งานเดิม/สิทธิผู้รับจ้างช่วง คำยินยอมศีลธรรม อายุ/วันลงนาม อำนาจ/ผลประโยชน์ขัดกันและใบรับหนังสือบอกกล่าวครบ การแจ้ง DIP ไม่ใช่เงื่อนไขให้โอนมีผล

## 5. สิทธิทางศีลธรรม

ม.18 ผู้สร้างแสดงตนและห้ามบิดเบือน/ตัดทอน/ดัดแปลงจนเสียชื่อเสียงหรือเกียรติคุณ ทายาทฟ้องตลอดอายุ เว้นตกลงอื่นเป็นลายลักษณ์อักษร แยกจากโอนสิทธิทางเศรษฐกิจ

ร่าง **ยินยอม/งดใช้สิทธิ** เฉพาะการแก้ แปล รวม แตกสาขาและเครดิตที่ตกลง ระบุผู้ได้ประโยชน์ ขอบเขตและทายาทเท่าที่กฎหมายอนุญาต ไม่รับรองว่าสละทั้งหมดได้ในทุกประเทศ ไม่ใช้เป็นอนุญาตบิดเบือนนอกขอบเขต refactor ไม่เสียชื่อเสียงทุกกรณีต้องตรวจจริง OSS ยังต้องรักษาประกาศตาม licence

## 6. เลือกเครื่องมือ

| เป้าหมาย | เครื่องมือ |
|---|---|
| เจ้าของเพื่อระดมทุน/ขายกิจการ | โอนตลอดอายุ + ยินยอมศีลธรรม + manifest |
| ผู้โอนใช้ต่อ | โอน + licence-back ระบุ ม.16 |
| ใช้เฉพาะเขต/สาขา/เวลา | licence ตรวจ ม.15(5) |
| เอกสารเก่าไม่ครบ | โอนใหม่ + อนุญาตอดีต/ปลดข้อเรียกร้อง ไม่ย้อนหลัง |
| ลูกจ้าง/ผู้รับจ้าง | ข้อตกลง ม.9, 10 + โอนสำรอง/ยืนยันงานอนาคต |

แม่แบบใน `templates.md`; ข้อสัญญาอื่นส่ง `thai-contract-master`
