# conflict_of_laws_and_foreign_judgments.md — กฎหมายขัดกันและคำพิพากษาต่างประเทศ

อ่านไฟล์นี้เมื่อเลือกกฎหมายต่างประเทศ มีนิติสัมพันธ์หลายประเทศ หรือใช้คำพิพากษาต่างประเทศในไทย

ข้อมูล ณ 9 ตุลาคม 2569 (2026) — **(สรุปสาระ)** กฎหมายที่ใช้กับการเลือกศาลเป็นคนละเรื่อง

---

## สารบัญ
1. ผังเลือกกฎหมาย
2. สัญญา ความสามารถ และละเมิด
3. พิสูจน์กฎหมายต่างประเทศ
4. คำพิพากษาต่างประเทศและ Hague
5. แผนฟ้องใหม่

## 1. ผังเลือกกฎหมาย

ลักษณะสิทธิ → บทกฎหมายขัดกัน → จุดเกาะเกี่ยว → กฎหมายภายในที่เลือก → ความสงบเรียบร้อย → วิธีพิสูจน์ ไม่ใช้สัญชาติคู่สัญญาเป็นคำตอบทุกประเด็น

| พ.ร.บ.ว่าด้วยการขัดกันแห่งกฎหมาย พุทธศักราช 2481 | หลัก |
|------------------------------------------------|------|
| ม.3 | ช่องว่างใช้กฎเกณฑ์ทั่วไปแห่งกฎหมายระหว่างประเทศแผนกคดีบุคคล ไม่เลือกตามประโยชน์ฝ่ายตน |
| ม.5 | กฎหมายต่างประเทศใช้ได้เท่าที่ไม่ขัดความสงบเรียบร้อย/ศีลธรรมไทย ไม่ปฏิเสธเพียงถ้อยคำต่าง |
| ม.7 | สัญชาตินิติบุคคลกรณีขัดกันดูสำนักงาน/ที่ตั้งทำการแห่งใหญ่ ไม่ใช้แทนความสามารถบุคคลธรรมดา |
| ม.8 | ไม่พิสูจน์กฎหมายต่างประเทศให้พอใจศาล ใช้กฎหมายภายในไทย ไม่ยกฟ้องอัตโนมัติ |
| ม.9 | แบบนิติกรรมตามประเทศที่ทำ เว้นบทอื่น; แบบจำเป็นเกี่ยวอสังหาริมทรัพย์ตามที่ทรัพย์ตั้ง |
| ม.10 | ความสามารถบุคคลตามสัญชาติ พร้อมข้อเฉพาะคนต่างด้าวทำนิติกรรมไทย/อสังหาริมทรัพย์ |
| ม.13 | สาระสำคัญ/ผลสัญญาตามเจตนา ไม่ทราบใช้กฎสำรองในมาตรา |
| ม.15 | ละเมิดตามที่ข้อเท็จจริงเกิด พร้อมข้อจำกัดการเป็นละเมิดและเยียวยาตามไทย |

ตัวบท **C1** ในคู่มือกรมการปกครอง ภาคผนวกหน้าพิมพ์ 104–106 (PDF 121–123); ม.2 มีผลตั้งแต่ประกาศ 20 มีนาคม 2481 ซึ่งอยู่ก่อนเปลี่ยนระบบปีพุทธศักราช ห้ามแปลง ค.ศ.ด้วยลบ 543 โดยไม่ตรวจ

## 2. สัญญา ความสามารถ และละเมิด

**ม.13:** เจตนาชัดแจ้ง/โดยปริยายก่อน หากไม่ทราบ: สัญชาติเดียวกันใช้กฎหมายสัญชาติร่วม; ต่างกันใช้ที่ทำสัญญา; บุคคลห่างกันดูที่คำสนองถึงผู้เสนอ; หยั่งทราบไม่ได้ใช้ที่พึงปฏิบัติตามสัญญา แบบถูกกฎหมายที่ใช้กับผลสัญญาไม่เป็นโมฆะเพราะแบบตามเงื่อนไขมาตรา เก็บคำเสนอ/สนองและที่เกี่ยวข้องในสัญญาออนไลน์ ไม่ถือว่าเซิร์ฟเวอร์เป็นที่ทำสัญญาเสมอ

**ม.10:** แยกความสามารถผู้ทำจากอำนาจแทน ข้อเฉพาะคนต่างด้าวทำนิติกรรมในไทยไม่ใช้ครอบครัว/มรดกตามมาตรา เลือกกฎหมายสัญญาไม่แก้ความสามารถ และอย่าขยายหลักบุคคลธรรมดาไปนิติบุคคลโดยไม่มีฐาน

**ม.15:** ข้อเท็จจริงต่างประเทศต้องเป็นละเมิดตามไทยด้วย การเยียวยาไม่เกินไทยยอมให้เรียก กรณีซอฟต์แวร์เสียหายหลายประเทศแยกเหตุ การกระทำ ความเสียหายและสิทธิ ไม่ฟันธงจากที่ตั้งเว็บไซต์

ข้อสัญญาอนุญาโตตุลาการแยกจากกฎหมายสัญญาหลัก; สาระสัญญาให้ `thai-contract-master` รับช่วง

## 3. พิสูจน์กฎหมายต่างประเทศ

ฐาน ม.8 ร่วมภาระพิสูจน์ทั่วไป **ป.วิ.พ. ม.84/1** แนบลิงก์หรือ legal opinion อย่างเดียวไม่ได้บังคับศาลให้ยอมรับ เตรียม:
- ตัวบททางการฉบับที่ใช้ในเหตุการณ์และประวัติแก้ไข
- คำแปลไทย/วิธีรับรอง พร้อมหลักตีความและคดีที่ตรวจจริง
- คุณสมบัติ/ความเห็นผู้เชี่ยวชาญ แยกกฎหมายจากข้อเท็จจริงที่ได้รับ
- วิธีนำสืบที่ให้อีกฝ่ายตรวจและถามค้านได้

ตารางทำงาน: ประเด็น → มาตราต่างประเทศ/ฉบับ → คำแปล → ผู้เชี่ยวชาญ/วิธีนำสืบ → คัดค้าน หากยังพิสูจน์ไม่ได้ บอกความเสี่ยงใช้ไทยตาม ม.8 ไม่รับประกันว่าจะใช้กฎหมายที่เลือกทุกส่วน [ป.วิ.พ. ศาลเผยแพร่ P1](https://jla.coj.go.th/th/file/get/file/20260602f59cc9d00473a5dfbed07a09e96c11ad145632.pdf)

## 4. คำพิพากษาต่างประเทศและ Hague

ไทยไม่มีระบบทั่วไปขอหมายบังคับคำพิพากษาศาลต่างประเทศเสมือนคำพิพากษาไทยโดยตรง ต้องพิจารณา **ฟ้องใหม่ในไทย** คำพิพากษาอาจเป็นหลักฐานแห่งหนี้ ไม่ผูกพันให้ไทยรับโดยอัตโนมัติ ตรวจฐานหนี้เดิม เขตอำนาจ ความเป็นที่สุด การแจ้ง/โอกาสต่อสู้ กฎหมายที่ต้องพิสูจน์และ public policy ไม่ใช้ 3 ปี ม.42 ของคำชี้ขาดหรืออายุความเดียวทุกมูลหนี้

แหล่ง **F1**: [The Interlaw Times Vol.6 สำนักงานศาลยุติธรรม](https://jla.coj.go.th/th/file/type/thumbnail/size/1500/file/2020010746cb7f4cf7c7b020c022538dbc82c84b151219.jpg) เป็นแนวอธิบาย ไม่ใช่กฎหมายรับรองทั่วไป ไม่อ้างเลขฎีกาที่ไม่ได้เปิดคำพิพากษาจริง

| สนธิสัญญา | สถานะไทย/ผล |
|------------|-------------|
| Hague Choice of Court 2005 | ไม่ปรากฏลงนาม/เป็นภาคี ข้อเลือกศาลไม่สร้างสิทธิบังคับไทยผ่านอนุสัญญา |
| Hague Judgments 2019 | ไม่ปรากฏลงนาม/เป็นภาคี ไม่ใช้เป็นฐานรับรองไทย |

ตรวจ [HCCH 2005](https://www.hcch.net/en/instruments/conventions/status-table/?cid=98), [HCCH 2019](https://www.hcch.net/en/instruments/conventions/status-table/?cid=137), [ทะเบียนไทย](https://www.hcch.net/en/states/hcch-members/details1/?sid=130) สมาชิก HCCH ไม่ใช่ภาคีทุกฉบับ ประเทศทรัพย์อื่นต้องตรวจขอบเขตของตน ไม่เหมารวมว่าไม่มีความตกลงเฉพาะใดเลย

## 5. แผนฟ้องใหม่

1. ระบุสิทธิ/หนี้ ทรัพย์ เขตอำนาจและบทกฎหมายขัดกัน ไม่ยื่นคำพิพากษาเป็นช่องทางบังคับตรง
2. รับเต็มฉบับ หลักฐานที่สุด คำคู่ความ ส่งหมายและหนี้เดิมพร้อมคำแปล
3. พิสูจน์กฎหมาย/เตรียมคัดค้าน ส่งฐานฟ้องจริงให้ผู้คำนวณกำหนด
4. ประเมินคุ้มครองไทยและประเทศอื่น ไม่ย้ายคำสั่งต่างประเทศมาใช้เอง
5. ส่ง `thai-litigation-pleadings` ร่างคดี; สัญญาใหม่เทียบศาล/อนุญาโตตุลาการตามทรัพย์จริง

```text
บันทึกเลือกกฎหมาย / Choice-of-law memorandum
ประเด็น / Issue: [สัญญา ความสามารถ ละเมิด หรือผลคำพิพากษา]
จุดเกาะเกี่ยว / Connecting facts: [กระทำ คำเสนอ/สนอง สัญชาติ ทรัพย์]
ฐานไทย / Thai basis: [มาตราและฉบับที่เปิดจริง]
ต่างประเทศ / Foreign law: [ฉบับ วันมีผล บทที่ใช้]
พิสูจน์ / Proof: [ตัวบททางการ คำแปล ผู้เชี่ยวชาญ วิธีนำสืบ]
ข้อจำกัด / Limits: [public policy วิธีเยียวยา หลักฐานขาด]
แผน / Recommendation: [ทางหลัก สำรอง ผู้รับผิดชอบ]
```

## หลักการ
- governing law, jurisdiction และ enforcement เป็นคนละคำถาม
- กฎหมายต่างประเทศต้องพิสูจน์ ไม่ใช่สิ่งศาลไทยต้องรู้เอง
- คำพิพากษาต่างประเทศเป็นหลักฐานที่ต้องวิเคราะห์ ไม่ใช่หมายบังคับไทย
- ชื่อกฎหมายไทย/อังกฤษเมื่อผู้ใช้ภาษาอังกฤษ พร้อม "ข้อสังเกตจากทนาย"
