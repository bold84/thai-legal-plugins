## 1. หนังสือขอหารือ

**วิธีปฏิบัติ:** ประมวลรัษฎากรไม่มีบทให้สิทธิขอหารือเป็นการเฉพาะ และ **หนังสือตอบข้อหารือไม่เป็นคำสั่งทางปกครอง** ตาม ม.5
พ.ร.บ.วิธีปฏิบัติราชการทางปกครอง พ.ศ. 2539 จึงอุทธรณ์ตามกฎหมายนั้นไม่ได้ และไม่ผูกพันคู่กรณีในทางกฎหมาย [L19]

```
วันที่ [....]
เรื่อง  ขอหารือเกี่ยวกับ [ประเภทภาษี/ประเด็น]
เรียน  อธิบดีกรมสรรพากร
1. ผู้หารือ  [ชื่อ/เลขประจำตัวผู้เสียภาษีอากร/สถานะ]
2. ข้อเท็จจริง  [ลำดับเหตุการณ์ วันที่ จำนวนเงิน คู่สัญญา เอกสารอ้างอิง]
3. ประเด็นที่ขอหารือ  [ระบุเป็นข้อ ๆ ให้ชัดและแคบ]
4. ข้อกฎหมายที่หารือ  [มาตรา/กฎหมายลำดับรอง + วันที่ใช้บังคับ]
5. ความเห็นเบื้องต้น  [สรุปสั้น]        6. เอกสารแนบ  [ระบุ]
                                     ขอแสดงความนับถือ  [ผู้หารือ/ผู้รับมอบอำนาจ]
```
**ต้องเติม:** ข้อเท็จจริงต้องครบเพราะคำตอบผูกพันเฉพาะกรณีนั้น

## 2. หนังสือนำส่งเอกสารและชี้แจงตามหมายเรียก

**ฐานกฎหมาย:** หมายเรียกตาม ม.19 (แสดงรายการไม่ถูกต้อง/ไม่บริบูรณ์; ออกได้ภายใน 2 ปี ขยายถึง 5 ปี; ให้เวลาล่วงหน้า ≥7 วัน)
หรือ ม.23 (ไม่ยื่นรายการ) · เพิกเฉย → ประเมินโดย **ห้ามอุทธรณ์** ตาม ม.21 หรือ ม.25 และมีโทษตาม ม.36 · การขอบัญชีจ่ายเงินได้
ตาม ม.51 ต้องปฏิบัติภายใน 15 วัน · การให้ถ้อยคำใช้หนังสือมอบอำนาจให้ถ้อยคำ (แบบ ท.5) [L2][L3][L17]

```
วันที่ [....]
เรื่อง  นำส่งเอกสารและชี้แจงข้อเท็จจริงตามหมายเรียกที่ [เลขที่/วันที่]
เรียน  เจ้าพนักงานประเมิน [สำนักงานสรรพากรพื้นที่ ....]
1. อ้างถึงหมายเรียกที่ [....] ซึ่งได้รับเมื่อวันที่ [....]
2. นำส่งเอกสาร  [ทะเบียนรายการ: บัญชี ใบเสร็จ สัญญา ใบกำกับภาษี ภ.ง.ด.53/3]
3. ชี้แจงรายประเด็น  1: [ข้อเท็จจริง + เอกสาร + ข้อกฎหมาย]   2: [....]
4. เอกสารที่นำส่งไม่ได้และเหตุผล [....] ขอขยายเวลาถึง [....]
5. ยินดีให้ความร่วมมือในการตรวจสอบไต่สวน
                                     ขอแสดงความนับถือ  [ผู้เสียภาษี/ผู้รับมอบอำนาจ]
```
**ต้องเติม:** ยื่นเป็นหนังสือเสมอและเก็บใบรับ · ให้ความร่วมมือเพราะเป็นเงื่อนไขขอลดหรืองดเบี้ยปรับตาม ท.ป.81/2542 ข้อ 2
ซึ่งแก้ไขโดย ท.ป.369/2569 [L14]

## 3. โครงคำอุทธรณ์การประเมิน

**ฐานกฎหมาย:** อุทธรณ์ **ตามแบบที่อธิบดีกำหนด** ตาม ม.28 ต่อคณะกรรมการพิจารณาอุทธรณ์ภายในกำหนดเวลาตาม ม.30 นับแต่วันรับแจ้ง ·
อุทธรณ์ไม่ทุเลาการเสียภาษี (ม.31) · คำวินิจฉัยของคณะกรรมการให้อุทธรณ์ต่อศาลได้ตาม ม.30 วรรคสอง · แบบที่ใช้คือ **แบบคำอุทธรณ์ ภ.ส.6**
(และ **กศก.171** สำหรับการประเมิน VAT ของเจ้าพนักงานกรมศุลกากร) [L1][L2][L12][L18]

```
แบบคำอุทธรณ์ (ภ.ส.6)  [ดาวน์โหลดฉบับปัจจุบัน]
วันที่ [....]
เรื่อง  อุทธรณ์การประเมินตามหนังสือแจ้งการประเมินที่ [....] ลงวันที่ [....]
เรียน  คณะกรรมการพิจารณาอุทธรณ์  [ผ่านหน่วยงานรับคำอุทธรณ์: สำนักงานสรรพากรภาค ....]
1. ผู้อุทธรณ์  [ชื่อ/เลขประจำตัว/ที่อยู่]
2. การประเมินที่อุทธรณ์  [ประเภทภาษี งวด/ปีภาษี เลขที่และวันที่หนังสือ วันที่รับแจ้ง ภาษี เบี้ยปรับ เงินเพิ่ม]
3. ข้อเท็จจริง  [ลำดับเหตุการณ์และวันที่]
4. ข้อโต้แย้งรายประเด็น  1: [ข้อเท็จจริง + ข้อกฎหมาย + หลักฐาน]   2: [....]
5. คำขอ  ขอยกเลิก/แก้ไขการประเมิน [และขอทุเลาการเสียภาษีถ้าประสงค์]
6. เอกสารแนบ  [หนังสือแจ้งการประเมิน แบบแสดงรายการ ใบกำกับภาษี สัญญา หลักฐานการชำระ]
                                     ลงชื่อ [....] ผู้อุทธรณ์/ผู้รับมอบอำนาจ
```
**ต้องตรวจ:** (ก) นับวันรับแจ้ง–ครบกำหนด; ถ้าพ้นกำหนดต้องยื่น **คำร้องขอขยายกำหนดเวลาการอุทธรณ์ต่ออธิบดี ตาม ม.3 อัฏฐ วรรคหนึ่ง**
[L10][L12] · (ข) ขอทุเลาการเสียภาษีให้ยื่น **คำร้องขอทุเลาการเสียภาษีอากรต่ออธิบดี** [L17][L2] · (ค) ชั้นคณะกรรมการ เจ้าพนักงานออก
หมายเรียกได้โดยให้เวลาล่วงหน้า ≥15 วัน และถ้าไม่ปฏิบัติอาจ **หมดสิทธิอุทธรณ์ต่อไป** ตาม ม.32 และ ม.33 [L2] · (ง) งานชั้นศาลส่ง
`thai-litigation-pleadings`/`thai-litigation-motions` และการนับวันส่ง `thai-litigation-deadlines`

## 4. คำขอลดหรืองดเบี้ยปรับหรือเงินเพิ่ม

**ฐานกฎหมาย:** เบี้ยปรับตาม ม.27 ทวิ วรรคสอง (ม.22, ม.26) ม.89 วรรคสอง และ ม.91/21 (6) งดหรือลดได้ตามหลักเกณฑ์ที่อธิบดีกำหนด
โดยอนุมัติรัฐมนตรี · ฉบับปัจจุบัน **ท.ป.81/2542 แก้ไขโดย ท.ป.369/2569** (ข้อ 2, 3, 5, 5/1, 14, 15, 17; ใช้บังคับ **3 กรกฎาคม 2569**)
และผู้มีอำนาจพิจารณาตาม **ท.ป.370/2569** (ใช้บังคับ **2 กรกฎาคม 2569**; ยกเลิก ท.ป.121/2545 และ 140/2547) [L13][L14][A6]

**เกณฑ์ที่ต้องอ้างให้ตรง:** ผู้ขอต้อง **ไม่มีเจตนาหลีกเลี่ยงภาษีและให้ความร่วมมือในการตรวจสอบไต่สวนด้วยดี** · ต้องยื่น **คำร้องเป็น
หนังสือต่อเจ้าพนักงานประเมินก่อนที่เจ้าพนักงานจะมีหนังสือแจ้งการประเมิน**; ถ้ารับแจ้งแล้วให้ **อุทธรณ์ต่อคณะกรรมการพิจารณา
อุทธรณ์** แทน · การขอคืนเบี้ยปรับต้องไม่เกินกำหนดเวลาที่มีสิทธิขอคืนภาษี · กรณีชำระ VAT/SBT พร้อมการยื่นแบบโดยไม่ถูกเตือนเป็น
หนังสือ ให้ถือว่าแบบแสดงรายการนั้นเป็นคำร้อง · เงินเพิ่มตาม ม.67 ตรี ลดตามข้อ 14 (นอกเหนือต้องได้อนุมัติอธิบดี) [L14]

```
แบบคำร้องของดหรือลดเบี้ยปรับหรือเงินเพิ่มภาษีอากร ตามประมวลรัษฎากร  [ดาวน์โหลดฉบับปัจจุบัน]
วันที่ [....]
เรื่อง  ขอ[งด/ลด]เบี้ยปรับ [หรือเงินเพิ่ม] ตาม [ม.22 / ม.26 / ม.67 ตรี / ม.89 / ม.91/21 (6)]
เรียน  เจ้าพนักงานประเมิน [สำนักงานสรรพากรพื้นที่ ....]
1. ผู้ร้อง  [ชื่อ/เลขประจำตัว/สถานะ]
2. รายการที่เกี่ยวข้อง  [ประเภทภาษี งวด เลขที่ วันที่ ภาษี เบี้ยปรับ เงินเพิ่ม]
3. เหตุที่ขอ [งด/ลด]  [ข้อเท็จจริงที่แสดงว่าไม่มีเจตนาหลีกเลี่ยงภาษีและได้ให้ความร่วมมือด้วยดี]
4. ข้อกฎหมาย  [มาตรา + ท.ป.81/2542 ซึ่งแก้ไขโดย ท.ป.369/2569 ข้อ .... + เงื่อนไขการลดตามข้อ 5 ถ้าเข้าเงื่อนไข]
5. เอกสารแนบ  [แบบแสดงรายการ หลักฐานการชำระ หลักฐานคำเตือน/หนังสือบันทึกความผิด]
                                     ลงชื่อ [....] ผู้ร้อง/ผู้รับมอบอำนาจ
```
**ต้องตรวจ:** อัตราลดใน ท.ป.369/2569 เป็นสัดส่วนตามเวลาชำระ (ต่ำสุดเมื่อชำระเร็วและไม่ถูกเตือน) — **อ่านอัตราจากคำสั่งฉบับจริง
อย่าจดจำ** [L14]

## 5. คำขอคืนภาษีและหนังสือติดตามการคืนภาษี

**ฐานกฎหมาย:** ขอคืนภายใน **3 ปี** นับแต่วันสุดท้ายแห่งกำหนดเวลายื่นรายการ ตาม ม.27 ตรี (มีข้อยกเว้น) และ **ตามแบบที่อธิบดีกำหนด** ·
ภาษีหัก ณ ที่จ่าย ม.63 · VAT ม.84 · SBT ม.91/11 · ดอกเบี้ยตาม ม.4 ทศ [L2][L3][L6][L9][L10]

```
แบบคำร้องขอคืนเงินภาษีอากร (ค.10)  [ดาวน์โหลดฉบับปัจจุบัน]
วันที่ [....]
เรื่อง  ขอคืนเงินภาษีอากร [ประเภทภาษี] งวด/ปีภาษี [....]
เรียน  [สรรพากรพื้นที่ ....]
1. ผู้ขอคืน  [ชื่อ/เลขประจำตัว/ที่อยู่/เลขบัญชี]
2. ภาษีที่ขอคืน  [ประเภท งวด จำนวน และเหตุ: ชำระเกิน มีสิทธิยกเว้น ภาษีซื้อมากกว่าภาษีขาย]
3. สิทธิและกำหนดเวลา  [ยื่นภายใน 3 ปีตาม ม.27 ตรี หรือตามมาตราเฉพาะของภาษีนั้น]
4. เอกสารแนบ  [แบบแสดงรายการ หลักฐานการชำระ ใบกำกับภาษี หนังสือรับรองการหักภาษี ณ ที่จ่าย]
```
**ติดตามผล/ถูกปฏิเสธ:** กรมสรรพากรออก **หนังสือแจ้งคืนเงินภาษีอากร** หรือ **หนังสือแจ้งไม่คืนเงิน (ค.30)** · หนังสือไม่คืนเงินเป็น
**คำสั่งทางปกครอง** (อุทธรณ์ตามหลัก พ.ร.บ.วิธีปฏิบัติราชการทางปกครอง พ.ศ. 2539) และข้อพิพาทขอคืนค่าภาษีอากรอยู่ในอำนาจ
**ศาลภาษีอากรตาม พ.ร.บ.จัดตั้งศาลภาษีอากรฯ มาตรา 7 (3)** [L19][L20]

```
วันที่ [....]
เรื่อง  ติดตามผลการคืนเงินภาษีอากรตามคำร้องที่ [....] ลงวันที่ [....]
เรียน  [สรรพากรพื้นที่ ....]
ข้าพเจ้ายื่นคำขอคืนภาษีอากรตามรายการข้างต้นเมื่อวันที่ [....] แต่ยังไม่ได้รับผล ขอได้โปรดพิจารณาและแจ้งผล
ให้ทราบภายใน [....] วันนับแต่วันที่ได้รับหนังสือนี้
```

## 6. ข้อสัญญาภาษีภายในประเทศ (ไทย/อังกฤษ)

**ฐานกฎหมาย:** VAT — ผู้ประกอบการจดทะเบียนเรียกเก็บจากผู้ซื้อ/ผู้รับบริการ และ **แสดงราคารวม VAT ได้** ตาม ม.82/4 [L7] ·
WHT — ผู้จ่ายเงินได้ตาม ม.40 ต้องหักตาม ม.50 และ **ออกหนังสือรับรองการหักภาษี ณ ที่จ่าย** ตาม ม.50 ทวิ; ถ้าไม่หัก/หักไม่ครบ
**ผู้จ่ายรับผิดร่วม** ตาม ม.54 [L3] · อากรแสตมป์ — ตราสารตามบัญชีต้องปิดแสตมป์บริบูรณ์ตาม ม.104 และ **เว้นแต่มีข้อตกลงเป็นอย่างอื่น**
ผู้มีหน้าที่เสียอากรและผู้ขีดฆ่าเป็นไปตามบัญชีท้ายหมวด ตาม ม.107 [L4][L5]

```
(ไทย)
1. ราคา  ราคาตามสัญญานี้ [ไม่รวม/รวม]ภาษีมูลค่าเพิ่มในอัตราที่กฎหมายกำหนดในแต่ละงวด; หากอัตรา ณ วันออกใบกำกับภาษี
   เปลี่ยนแปลง ราคาสุทธิให้เป็นไปตามที่กฎหมายกำหนด
2. ภาษีหัก ณ ที่จ่าย  ผู้จ่ายมีสิทธิหักตามจำนวนที่กฎหมายกำหนดจากเงินที่ต้องชำระ และจะออกหนังสือรับรองให้ภายใน
   กำหนด หากหักไม่ครบผู้จ่ายต้องรับผิดร่วมตามมาตรา 54
3. อากรแสตมป์  อากรแสตมป์ (ถ้ามี) ให้ผู้มีหน้าที่เสียอากรตามบัญชีอัตราอากรแสตมป์รับภาระและปิดแสตมป์บริบูรณ์ภายใน
   กำหนดเวลาตามกฎหมาย; ถ้าตกลงให้ฝ่ายใดรับภาระแทน ให้ระบุให้ชัดและไม่กระทบหน้าที่ต่อกรมสรรพากร
4. ภาษีอื่น  ภาษีที่เกิดใหม่ให้เป็นไปตามข้อตกลง [ระบุฝ่าย] แต่ความรับผิดต่อหน่วยงานรัฐไม่อาจโอนหรือจำกัดได้โดยข้อสัญญา

(English)
1. Fees. All amounts are exclusive of VAT (unless stated to be inclusive); VAT at the rate applicable on the
   date of the tax invoice shall be added and borne by the Customer.
2. Withholding Tax. The payer shall withhold tax as required by the Revenue Code and issue a withholding tax
   certificate. The fees are stated [gross/net] of such withholding tax.
3. Stamp Duty. Stamp duty, if any, shall be borne by the party liable under the Revenue Code and the instrument
   shall be duly stamped; this clause does not limit any statutory liability.
```
**ต้องตรวจ:** เลือกให้ชัดว่าราคา **รวม** หรือ **ไม่รวม** VAT; ห้ามใช้ข้อสัญญาเพื่อโอนหรือจำกัดความรับผิดต่อกรมสรรพากร; ระบุว่าใครรับภาระ
WHT และผู้รับจะได้เงินสุทธิเท่าใด; ชี้ว่าฝ่ายใดเสียอากรแสตมป์ตามบัญชีท้ายหมวด (เพื่อเลี่ยงข้อพิพาทจาก ม.107) และเตือนผลของ ม.113/114
(เงินเพิ่มอากร) และ ม.118 (ใช้เป็นพยานในคดีแพ่งไม่ได้) [L4]

## 7. บันทึกความเห็นภาษีภายใน

```
บันทึกความเห็นภาษีอากร
ถึง [....]   จาก [....]   วันที่ [....]   เรื่อง [ประเด็น]
ข้อมูล ณ [วันที่อ้างอิงกฎหมาย]   (สถานะ: ร่างให้ทนายตรวจรับรอง)
1. คำถาม/ประเด็น
2. คำตอบโดยสรุป (Bottom line)  [ตอบตรงประเด็น + ระดับความเชื่อมั่น]
3. ข้อเท็จจริงและสมมติฐาน  [และข้อมูลที่ยังขาด]
4. ข้อกฎหมาย  [มาตรา + กฎหมายลำดับรอง + วันที่ใช้บังคับ; แยกตัวบทกับ (สรุปสาระ)]
5. การวิเคราะห์  [ปรับกฎหมายเข้ากับข้อเท็จจริง + พิจารณาข้อโต้แย้งของเจ้าพนักงานทั้งสองด้าน]
6. ภาษี เงินเพิ่ม เบี้ยปรับ และกำหนดเวลา  [ตาราง: ประเภทภาษี | ฐาน | วันที่ใช้บังคับ | แบบ | กำหนดเวลา | หลักฐาน]
7. ความเสี่ยงและข้อเสนอแนะ  [แนวปฏิบัติเพื่อความสอดคล้อง หรือแนวโต้แย้ง]
8. ข้อจำกัดของบันทึก  [ขอบเขต ข้อมูลที่ขาด และสิ่งที่ต้องตรวจกับฉบับปัจจุบัน]

ข้อสังเกตจากทนาย
🔴 [ความเสี่ยงสูง — มีโทษ ภาษีหรือเงินเพิ่มจำนวนมาก หรืออาจเสียสิทธิ]
🟡 [ความเสี่ยงปานกลาง — การจำแนกประเภท หลักฐาน หรือกำหนดเวลาขัดกัน]
🟢 [ข้อแนะนำด้านเอกสารและกระบวนการ]
📝 [ข้อมูลหรือตัวเลขที่ต้องยืนยันกับฉบับปัจจุบัน]
```

## หลักการ

- เลือกแม่แบบให้ตรงขั้นตอนจริง (ชั้นเจ้าพนักงาน/ชั้นอุทธรณ์/ชั้นศาล) และใช้แบบฟอร์มราชการฉบับปัจจุบันเสมอ [L17]
- อย่าตัดส่วนข้อเท็จจริง จำนวนเงิน วันที่ และหลักฐานออก แม้ในเวอร์ชันสั้น
- อ้างมาตราและกฎหมายลำดับรองพร้อมวันที่ใช้บังคับ และแยกตัวบทกับ (สรุปสาระ)
- ปิดท้ายงานความเห็นด้วย "ข้อสังเกตจากทนาย" จัดอันดับ 🔴 / 🟡 / 🟢 / 📝
