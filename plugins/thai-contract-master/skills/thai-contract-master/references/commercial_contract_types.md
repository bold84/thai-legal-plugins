## 2. (a) B2B SaaS/subscription

**ข้อหลัก:** scope/usage/affiliate · SLAนิยามavailability+เครดิต+ข้อยกเว้น · ระงับเมื่อไม่ชำระ (ม.369/notice/cure) · ราคา/ต่ออายุ · IP/indemnity · cap · data exit/export/deletion · AI-output/ฝึกข้อมูล → `thai-ai-governance`, `thai-copyright-software`

**กับดัก:** B2B สำเร็จรูปยังตรวจข้อสัญญาฯ ม.3–4/8/10 และ ม.373; credit ไม่ลบทุกสิทธิ ม.13/1 ของ พ.ร.บ.ธุรกรรมฯ คือข้อเสนอต่อสาธารณะ ไม่ใช่ทุกorder; DPA ม.40 ว.3 → `thai-pdpa` อากรตามเนื้อหาไม่ใช่ชื่อ SaaS → `thai-tax-revenue-code`

**Checklist:** [ ] scope/usage [ ] uptimeสูตร/เหตุยกเว้น [ ] creditสัมพันธ์สิทธิอื่น [ ] ระงับเท่าที่จำเป็น+cure [ ] DPAversionตรงMSA [ ] export/ค่าexit [ ] ราคาไม่ย้อนหลัง [ ] AIไม่ใช้ข้อมูลนอกข้อตกลง B2C/แพลตฟอร์ม → `thai-ecommerce-consumer` / `thai-tech-platform-law`

## 3. (b) พัฒนาซอฟต์แวร์เป็นจ้างทำของ

**ข้อหลัก:** spec/testcases · changecontrol/ผู้อนุมัติ · งวด ม.602 · UAT ม.597–598 · ตรวจงาน ม.592 · warranty ม.600 · เลิกก่อนเสร็จ/ชดใช้ ม.605 · จ้างช่วง ม.607 · source/build/docs · escrow · IP/OSS

**กับดัก:** พ.ร.บ.ลิขสิทธิ์ฯ ม.10 อาจให้ผู้ว่าจ้างเจ้าของตั้งแต่ต้น ไม่ต้องโอนซ้ำทุกงาน; ม.17 โอนต้องหนังสือสองฝ่าย ไม่ระบุเวลา=10ปี; ธรรมสิทธิ ม.18 ไม่ใช้ waiverรวบยอด ผู้รับช่วง/ของเดิม/OSSให้ `thai-copyright-software` ตรวจ รับไม่ทักท้วง ม.598 อาจปลดบกพร่องเว้นซ่อน/ปกปิด; ม.600ช่วงรับผิด ≠ ม.601อายุความ freelancerตรวจงานจริงตาม ม.575/587

**Checklist:** [ ] scope/change/งวด [ ] งาน/source/docsพร้อมUAT [ ] เหตุปฏิเสธ/ทดสอบซ้ำ [ ] repo/build/dependency [ ] IPschedule [ ] escrowสามฝ่าย:สิ่งฝาก/ทดสอบ/เหตุปล่อย/licenceหลังปล่อย ฝากsourceไม่ให้สิทธิใช้เอง

## 4. (c) Licence IP: รับช่วง `thai-trademark` / `thai-patent`

**Term sheet:** scheduleสิทธิ/เจ้าของร่วม · field/สินค้า/พื้นที่ · exclusive/sole/non-exclusiveนิยามจริง · sublicense/โอน · ระยะ · ค่าสิทธิ/รายงาน/audit · quality · improvements/grant-back · บังคับสิทธิ · เลิก/sell-off · ผู้ยื่นจด/ค่าใช้จ่าย

| สิทธิ | ข้อบังคับ/ค่าเริ่มต้น |
|---|---|
| เครื่องหมายจดทะเบียน | ม.68 หนังสือ+ทะเบียน ระบุควบคุมคุณภาพ/สินค้า; ม.69 ตรวจสับสน/สงบเรียบร้อย; ม.70 ใช้ของผู้รับ=เจ้าของ; ม.76 ทะเบียนเครื่องหมายถูกเพิกถอน licenceสิ้น |
| ค่าเริ่มต้น TM เว้นตกลงอื่น | ม.77 เจ้าของใช้/ให้คนอื่นได้; ม.78 ทั่วประเทศทุกสินค้าที่จดตลอดอายุรวมต่ออายุ; ม.79 ห้ามโอน/ช่วง; ม.79/1 ไม่สิ้นเพราะโอน/มรดกเครื่องหมาย |
| สิทธิบัตร | ม.41 หนังสือ+ทะเบียน; ออกแบบ/อนุสิทธิบัตรอนุโลม ม.65,65 ทศ; ม.39 เงื่อนไขแข่งขันไม่ชอบธรรม/ค่าสิทธิหลังหมดอายุโมฆะ; ม.40 เจ้าของร่วมยินยอมทุกคน; ม.55(2) ฝ่าฝืน41เป็นเหตุเสนอเพิกถอน |
| ลิขสิทธิ์ (ส่งเจ้าของสกิล) | ม.15(5) เงื่อนไขไม่จำกัดแข่งขันไม่เป็นธรรม; ม.16 เจ้าของให้คนอื่นได้เว้นหนังสือห้าม; ไม่ใช้แบบทะเบียนTMแทนกฎหมายลิขสิทธิ์ |

**กับดัก:** TMผิดแบบเสี่ยงโมฆะ ป.พ.พ. ม.152; foreign-law clauseไม่ใช่ทางเลี่ยงตามบทวิเคราะห์ Tillekeที่อ้างใน `key_sections.md` อย่ารวมการขายสินค้าของเจ้าของกับการอนุญาตใช้เครื่องหมายในกิจการตนจากชื่อ reseller แยก patent/know-howและมูลค่าจริง ไม่เปลี่ยนชื่อเพื่อเก็บค่าสิทธิบัตรหลังหมดอายุ

**Checklist:** [ ] ทะเบียน/สินค้า/ประเทศ [ ] exclusiveตัดใช้เจ้าของไหม [ ] ช่วง/โอน+flow-down [ ] royalty/report/audit [ ] quality:มาตรฐาน/ตัวอย่าง/ตรวจ/แก้/ระงับ [ ] จดจริงก่อนใช้ [ ] คุมคดี/ค่าใช้จ่าย [ ] เลิก/คืน/sell-off ให้สกิลIPยืนยันสิทธิจริง

## 5. (d) Distribution/reseller/agency

แยกขายในนามตัวการ (ม.797) จากซื้อขายในนามตน/นายหน้า (ม.845) **ข้อหลัก:** territory/exclusivity · เป้ายอด · อิสระขายต่อ · TM · support/warranty/recall · ลูกค้า · เลิก/transition/stock/sell-off

**กับดัก:** ม.824 ตัวการอยู่+ภูมิลำเนาต่างประเทศ; ม.801 ต้องอำนาจเฉพาะฟ้อง/ประนีประนอม/อนุญาโตฯ; ม.827 ว.2 เลิกเวลาไม่สะดวกชดใช้เว้นเหตุจำเป็นที่ก้าวล่วงไม่ได้ ไม่รับรอง goodwill indemnity อัตโนมัติทุกdistributor กฎหมายตลาดปลายทางอาจต่าง

**Competition sanity check:** พ.ร.บ.การแข่งขันฯ ม.54 คู่แข่ง/คาร์เทล แยกจาก ม.55 แนวดิ่ง/sole distributor(3); ต้องมีผลลด/จำกัดแข่งขัน ม.56ข้อยกเว้นมีเงื่อนไข ไม่ใช่ทุกlicenceพ้นผิด ม.57ความเสียหาย+ไม่เป็นธรรมตามแนวทาง2565 ไม่ใช้ส่วนแบ่ง10%เป็นsafeharbourทุกมาตรา ตรวจประกาศplatform/creditterm2569ใน `key_sections.md`

**Checklist:** [ ] ผู้ออกinvoice/รับเงิน/ผูกตัวการ [ ] ลูกค้า/พื้นที่ไม่คาร์เทล [ ] exclusivityมีเหตุ/ข้อมูลตลาด [ ] exit/stock [ ] โอนsubscriptionลูกค้า [ ] กฎหมายปลายทาง ภาษีข้ามพรมแดน (ในประเทศ `thai-tax-revenue-code`)/ต่างด้าว/ส่งออก → `thai-tax-international`, `thai-boi-foreign-business`, `thai-export-control`

## 6. (e) NDA

**ข้อหลัก:** ข้อมูล/ข้อยกเว้น · purpose · need-to-know · ระยะ/ความลับที่ยังลับ · คืน/ทำลาย · เปิดเผยตามกฎหมาย · PDPA · remedies

**กับดัก:** non-competeแฝงข้อสัญญาฯ ม.5; penaltyลด ม.383; ลูกจ้าง ม.14/1 พ.ร.บ.คุ้มครองแรงงานฯ สาระความลับการค้า → `thai-copyright-software`

**Checklist:** [ ] นิยาม/ข้อยกเว้นพิสูจน์ได้ [ ] ผู้รับจำเป็นมีหน้าที่ [ ] เปิดเผยบังคับแจ้งเท่าที่ทำได้ [ ] backup/เก็บตามกฎหมาย [ ] residualไม่เปิดใช้source/know-how [ ] ไม่รับรองinjunctionอัตโนมัติ

## 7. (f) Consulting/services

**ข้อหลัก:** จัด ม.575/587 · deliverable/ผู้ทำ (ม.577,607) · ค่าตอบแทน/ค่าใช้จ่าย · licenceวิชาชีพ · conflict · IPเดิม/ใหม่ · cap · exit

**กับดัก:** เลิกทำของ ม.605 ต่างจากแรงงานไม่กำหนดเวลา ม.582; IPรับจ้าง ม.10 พ.ร.บ.ลิขสิทธิ์ฯ ไม่ใช่รับรองเครื่องมือทุกชิ้นของผู้ว่าจ้าง อากร/WHT → `thai-tax-revenue-code` (ผู้รับต่างประเทศ `thai-tax-international`)

**Checklist:** [ ] ผลสำเร็จหรือทำต่อเนื่อง [ ] คนหลัก/ช่วง [ ] วิชาชีพ/conflict [ ] scopeตามข้อมูล [ ] acceptance/expense [ ] IPschedule [ ] exitไม่ค้างงาน/ข้อมูล

## 8. (g) Employment/contractor

**ข้อหลัก:** หน้าที่/ค่าจ้าง · IP · confidentiality · non-compete · อุปกรณ์/ข้อมูล · สิ้นสุด/ส่งต่อ

**กับดัก:** พ.ร.บ.คุ้มครองแรงงานฯ ม.14/1 ปรับความได้เปรียบ; ม.54 เงินไทยเว้นยินยอม โดย ม.77 ต้องหนังสือลงชื่อเฉพาะ; ม.11/1 จัดหาคนตามองค์ประกอบ ไม่ใช่ทุกfreelancer ข้อสัญญาฯ ม.5 ไม่มีระยะห้ามแข่งมาตรฐานทุกงาน ลิขสิทธิ์ ม.9 ลูกจ้างผู้สร้างเว้นหนังสือ; สิทธิบัตร ม.11 สิทธิขอนายจ้างเว้นตกลงอื่น/ม.12 ค่าตอบแทนตัดไม่ได้

**Checklist:** [ ] สถานะตามงานจริง [ ] IPไม่ตัดธรรมสิทธิ [ ] ห้ามอาชีพเท่าที่จำเป็น [ ] non-compete:ประโยชน์/กิจกรรม/พื้นที่/เวลา [ ] คืนของ/ข้อมูล แรงงาน→`thai-compliance-audit`;IP→`thai-copyright-software` / `thai-patent`;permit→`thai-boi-foreign-business`

## 9. (h) DPA integration

PDPA ม.40 ว.3 ผู้ควบคุมต้องมีข้อตกลงกับผู้ประมวลผล ใช้ **แม่แบบ `thai-pdpa` ไม่ร่างซ้ำ** ใน MSAวางversion/ลำดับ/cap ไม่ตัดสิทธิภายนอก

**Checklist:** [ ] datamap/role [ ] DPAเดียวversionตรง [ ] คำสั่ง/ช่วง/คืนลบ/โอนตามผลPDPA [ ] เหนือMSAเฉพาะข้อมูล [ ] cap/indemnityไม่ตัดหน้าที่กฎหมาย

## 10. (i) Intra-group/related-party

**ข้อหลัก:** คู่สัญญาที่ใช้บริการจริง · service/asset/personnel · feeallocation · approval · IP/ข้อมูล · exit

**กับดัก:** self-dealing/สองฝ่ายต้องยินยอม ม.805; กรรมการแข่งขันต้องที่ประชุมใหญ่ยินยอม ม.1168 ว.3; ผู้ถือหุ้นมีส่วนได้เสียพิเศษห้ามออกเสียง ม.1185 ไม่เหมาบริษัทจำกัดกับมหาชน/จดทะเบียน → `thai-corporate-secretarial` กู้เกิน2,000หลักฐาน ม.653; เงินกู้เอกชนทั่วไป15%ภายใต้กฎหมายเฉพาะ ม.654/พ.ร.บ.ห้ามเรียกดอกเบี้ยเกินอัตราฯ ม.4 ราคาโอน/arm'slength → `thai-tax-international`

**Checklist:** [ ] บริการ/หลักฐานจริง [ ] ลงนามสองฝั่ง/ยินยอม [ ] มติ/กันเสียงตามบท [ ] allocation/ราคาให้สกิลภาษี [ ] invoiceตรงterms [ ] ไม่รับรองเครือพ้นแข่งขัน

## 11. การเปลี่ยนกฎหมายซื้อขาย

ตรวจราชกิจจานุเบกษาและผล `thai-ecommerce-consumer` ว่าร่างความรับผิดเพื่อชำรุดบกพร่องประกาศใช้แล้วหรือไม่ก่อนส่งมอบ **หากยังเป็นร่าง: ร่าง — ยังไม่มีผลใช้บังคับ** ไม่ใช้สิทธิหรือระยะในร่างแทน ป.พ.พ. ม.472–474 และไม่อนุมานวันใช้จากมติ ครม./รับหลักการ
