# clause_risk_library.md — คลังข้อสัญญาเสี่ยงและกับดักกฎหมายไทย

อ่านไฟล์นี้เมื่อตรวจ/ร่างข้อสัญญารายข้อ: ทุกแถวมีฐานกฎหมายที่ตรวจแล้ว (ตัวบท/แหล่งที่มา → `key_sections.md`) พร้อมแนวแก้ (redline → fallback) ข้อมูล ณ 9 ตุลาคม 2569 (2026); "ข้อวิเคราะห์" ไม่ใช่ตัวบทโดยตรง ต้องแจ้งผู้ใช้

ฐานกฎหมายทุกแถวเป็น **(สรุปสาระ)** จากแหล่งทางการใน `key_sections.md`; ตัวเลขในแนวแก้เป็น **ข้อเสนอเจรจา ไม่ใช่อัตราหรือกำหนดเวลาที่กฎหมายบังคับ** และไม่รับรองว่าเลือกตัวเลขนั้นแล้วจะบังคับได้

## 1. ระดับความเสี่ยง
🔴 โมฆะ/บังคับไม่ได้/มีโทษ · 🟡 ศาลลด/ตีความเป็นโทษผู้ร่าง · 🟢 ปรับถ้อยคำ · 📝 ตรวจฉบับปัจจุบัน/ฎีกา · "ข้อสัญญาฯ"=พ.ร.บ.ว่าด้วยข้อสัญญาที่ไม่เป็นธรรม · "ม." เปล่า=ป.พ.พ.

## 3. แผนผังตรวจเพดานความรับผิด
```
1 กลฉ้อฉล/ประมาทเลินเล่ออย่างร้ายแรงของเรา? → ตัดไม่ได้ (ม.373)
2 ชีวิต/ร่างกาย/อนามัยจากจงใจ-ประมาทของตนหรือผู้ต้องรับผิดด้วย? → อ้างตัดไม่ได้ (ข้อสัญญาฯ ม.8 ว.1)
3 อยู่ในขอบเขตสัญญาผู้บริโภค/สำเร็จรูป/ขายฝาก? → ทดสอบ ม.4+ม.10 ไม่ใช่อำนาจต่อรองอ่อนอย่างเดียว
4 ข้อยกเว้นอื่นที่ไม่โมฆะ → ทดสอบความเป็นธรรมตาม ม.8 ว.2; cap สองฝ่ายไม่ได้ทำให้เป็นธรรมโดยอัตโนมัติ
5 ม.220 ให้รับผิดคนที่ใช้ชำระหนี้ แต่ไม่ขยาย ม.373 อัตโนมัติ → เขียน carve-out ครอบคลุมบุคคลเหล่านี้ตามเจรจา
```

## 4. สัญญาณเตือน
"ไม่ว่ากรณีใดๆ/sole and exclusive" · เบี้ยปรับซ้อนหลายชั้น · เลิกได้โดยไม่มีเหตุ · ห้ามโอนแต่เราต้องโอนเมื่อควบรวม · กฎหมาย/ศาลต่างประเทศไร้ผู้เชี่ยวชาญ · licence TM/สิทธิบัตรไม่มีแผนจดทะเบียน · ผู้ลงนามไม่ตรงหนังสือรับรอง · ตราสารทำนอกประเทศไม่มีแผนเสียอากร
