## 1. รับโจทย์และแฟ้ม

ถามเฉพาะที่เอกสารไม่มี เก็บ draft/redline/ฉบับสะอาด ภาคผนวก PO/เว็บไซต์/DPA-SLA-SOWและหลักฐานยอมรับ ระบุ version/วันที่/ที่ขาด สำเนาtermsที่ตรวจไม่ใช่ URLอย่างเดียว จัดแต่ละส่วนตาม `commercial_contract_types.md` ไม่ใช้ชื่อ freelancer/distributor ตัดสิน

```
ฝ่ายเรา: [....]   โหมด: [ร่าง/ตรวจ/เจรจา/ลงนาม/ผิดสัญญา]
เอกสาร: [ชื่อ/version/วันที่/ภาคผนวก]   ประเทศ: [ลงนาม/ปฏิบัติ/IP/ข้อมูล]
งาน-เงิน-สิทธิ-ข้อมูล: [ใครส่งอะไร/เมื่อใด/เงินและสิทธิไปที่ใคร]
เป้าหมาย/ไม่รับ: [....]   สมมติฐาน/สิ่งไม่ตรวจ: [....]
```

## 2. ด่านความสมบูรณ์ก่อนต่อรอง

| ด่าน | ฐาน/สิ่งตรวจ | การจัดผล |
|---|---|---|
| เกิดหรือยัง | ม.354–361,366–367 เสนอ/สนอง/ข้อค้าง | ไม่อ้างdraftว่าผูกแล้ว; term sheetแยกข้อ |
| วัตถุ/เจตนา | ม.150–153,155–157,159,164 | แยกโมฆะ/โมฆียะ ไม่แก้ทุกเรื่องด้วยseverability |
| แบบ/หลักฐาน | ม.152,456,538,653,680; IPทะเบียน | โมฆะ ≠ ขาดหลักฐานฟ้อง |
| อำนาจ | ม.1144,1167,798,805; affidavit/มติ/POA/ตรา | ตรา ≠ อำนาจ; internalapproval ≠ ผูกบริษัท |
| ข้อบังคับ | ข้อสัญญาฯ ม.3–11/แรงงาน/PDPA/consumer | ผู้บริหารไม่อนุมัติข้อโมฆะให้ชอบได้ |
| พยาน/อากร | ธุรกรรมฯ ม.8–9,11; ป.รัษฎากร ม.104,111,118 | e-sign ≠ ครบอากร/ทะเบียน |

อำนาจ/มติส่ง `thai-corporate-secretarial`; อากรส่ง `thai-tax-international` ระบุ **เห็นเอกสารแล้ว/ยังไม่ได้รับ/ต้องยื่นจริง** ไม่เขียนตรวจแล้วจากคำรับรองในสัญญาอย่างเดียว

## 4. เจรจาและอนุมัติ

carve-out ม.373เป็นข้อจำกัดกฎหมาย; จำนวนcapเป็นเจรจา cureที่เสนอไม่ใช่วันทั่วไปตามกฎหมาย

```
ประเด็น/เหตุผลธุรกิจ: [....]   ฐาน/ข้อจำกัด: [....]
ต้องได้: [....]   opening: [....]   ยอมรับได้: [....]   ไม่รับ: [....]
ต้นทุนที่เหลือ/ผู้อนุมัติ: [....]   หลักฐาน/เงื่อนไขก่อนลงนาม: [....]
```

| เจ้าของตรวจ | ปิดด้วย |
|---|---|
| ธุรกิจ/การเงิน | scope/ราคา/SOW/ตารางเงินตกลง |
| กฎหมาย/บริษัท | affidavit/ข้อบังคับ/มติ/POA/issueที่ปิด |
| เทคโนโลยี/IP | spec/SLA/escrow/IPscheduleจากสกิลเฉพาะ |
| ข้อมูล/AI | ผล `thai-pdpa` / `thai-ai-governance` และเอกสารเดียว |
| ภาษี/ประเทศอื่น | ผล `thai-tax-international` / ผู้เชี่ยวชาญปลายทาง |

ไม่สมมติทุกบริษัทต้องมติใหญ่หรือมีตรา แยกผู้อนุมัติเชิงธุรกิจจากผู้มีอำนาจลงนามจริง

## 5. Signing checklist

- **ก่อน:** [ ] ชื่อทุกภาษาตรง [ ] version/แนบท้าย/ช่องเติมครบ [ ] อำนาจ/ร่วมลงชื่อ/ตรา/POA [ ] self-dealingยินยอม [ ] วันมีผล/เงื่อนไขก่อนงาน [ ] อากร/ทะเบียนเจ้าของชัด [ ] ศาล/ภาษาไม่ขัด
- **ขณะ:** [ ] ฐานะลงชื่อ [ ] ไม่เปลี่ยนภาคผนวก [ ] counterpartตรง [ ] e-signตัว/เจตนา/version/เวลา/audittrail ไม่ใช่ภาพลายเซ็นอย่างเดียว
- **หลัง:** [ ] ฉบับทุกฝ่าย [ ] e-stampผูกversion [ ] licenceจดจริง [ ] obligationregister/วันกระตุ้น [ ] หลักฐานต่ออายุ/รับงาน/สงวนpenalty/บอกผู้ค้ำ/คืนข้อมูล [ ] นิติกรณ์ตามผู้รับ

ลงนาม ≠ ใบทะเบียน ≠ อากร ≠ อนุมัติ เก็บแยกเชื่อมกัน การรับรองไม่รับรองเนื้อหาหรือรักษาอำนาจที่ไม่มี ไทยยังไม่เริ่มApostille ณ วันที่ข้อมูลนี้ → `formation_validity_and_execution.md`

## 6. สองภาษาและลำดับเอกสาร

```
| ข้อ | ไทย: สิทธิ/หน้าที่/เงื่อนไข/ข้อยกเว้น | อังกฤษ: ผลตรงไหม | แก้/ฉบับหลัก |
| [....] | [....] | [....] | [....] |
```

เทียบ shall/may, and/or, paid/payable, exclusive/sole, signing/effectivedate, actual/deemedreceipt และ term map ไม่แปลindemnityเป็นไม่จำกัดโดยอัตโนมัติ prevailinglanguageใช้ตีความระหว่างคู่สัญญา ไม่ยกเว้นแปลตาม ป.วิ.พ. ม.46 DPAเหนือMSAเฉพาะข้อมูล; POไม่ลบcap/ข้อหลักโดยปริยาย กำหนดผู้อนุมัติเปลี่ยน

## 7. ผิดสัญญาและคำบอกกล่าว

หนี้/กำหนด → ไม่ชำระ → ผิดนัด ม.204–205 → รับผิด ม.215,220 → เสียหายปกติ/พิเศษ/บรรเทา ม.222–223 → cap/penalty → เลิก/ผล ม.386–394 → หลักฐาน/อายุความ

```
| สิทธิ/องค์ประกอบ | วันที่/ข้อเท็จจริง | หลักฐาน | ข้อต่อสู้ | ฐานเงิน/ช่วง | ส่งต่อ |
| [หนี้/ผิดนัด/เลิก/เสียหาย] | [....] | [ฉบับ/email/UAT/รับnotice] | [ไม่ถึงกำหนด/รับแล้ว/force majeure/cap] | [ไม่เดา] | [อายุความ/คำฟ้อง/ข้อมูลขาด] |
```

- รับงานช้า: บอกสงวนจริงเมื่อรับตาม ม.381 ว.3 ไม่พึ่งประโยคในสัญญา → clause bankข้อ15
- เลิก: เหตุ/ผู้รับ/วิธี/รับจริง/เวลาพอสมควร ม.387 แยก ม.388–389 ไม่เปลี่ยนเตือนเป็นเลิกทันทีเสมอ
- ค้ำ: ม.686หนังสือภายใน60วันเป็นวันกฎหมาย ไม่ใช่cureที่ต่อรอง ผลช้าไม่หลุดต้นทั้งหมด
- ดอก: แบ่งช่วงก่อน/หลัง พ.ร.ก.2564 ตรวจอัตรา ม.7/ต้นงวดผิดนัด; warrantyไม่ใช่อายุความ

ส่ง `thai-litigation-deadlines` เรื่องวันฟ้อง; ส่ง `thai-litigation-pleadings` พร้อมองค์ประกอบ หลักฐานรับnotice ฐานคำนวณ ถ้าอนุญาโตฯส่ง `thai-international-disputes` ก่อนเลือกคดี

## 8. ส่งมอบและตัวอย่าง

ร่างใหม่=สัญญา/แนบท้าย+เหตุผล+signing; ตรวจ=issue/redline/สะอาดตามขอ+negotiation; พิพาท=claim/notice/หลักฐาน+route ห้ามทำเครื่องหมายผ่านข้อมูลไม่เห็น

| ข้อเดิม | ฐาน/ผล | redline → fallback |
|---|---|---|
| ไม่รับผิดทุกกรณี | 🔴 ม.373/ข้อสัญญาฯ ม.8,10 | capฐานชัด+carve-out → เจรจาวงอื่นแต่คงสิทธิห้ามตัด |
| รับทันทีที่แจ้ง | 🟡 ม.597–598,600–601 | UATเมื่อพร้อม/สิทธิซ่อน → deemedหลังเวลาพอจริง |
| โอนเครือแล้วหลุด | 🟡 ม.306,349–351 | แยกสิทธิ/ภาระ+เจ้าหนี้ยินยอม → ช่วงได้แต่เดิมรับผิด |

ทุกโหมดปิด **ข้อสังเกตจากทนาย** 🔴แก้ก่อนใช้ / 🟡เจรจา / 🟢ชัด-ทำได้ / 📝ต้องยืนยัน ระบุเจ้าของ/เงื่อนไขปิด เป็นร่างให้ทนายรับรอง ไม่รับประกันผลฟ้อง
