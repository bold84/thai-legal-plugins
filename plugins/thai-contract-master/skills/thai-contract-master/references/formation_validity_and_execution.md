## 1. ความสมบูรณ์และแบบ

```
ต้องห้ามชัดแจ้ง/พ้นวิสัย/ขัดความสงบเรียบร้อย → โมฆะ (ป.พ.พ. ม.150)
ต่างจากบทไม่เกี่ยวความสงบเรียบร้อย → ใช้ได้ (ม.151)
ผิดแบบ → โมฆะ (ม.152); ฝ่าฝืนความสามารถ → โมฆียะ (ม.153)
เจตนาลวง/สำคัญผิดสาระ → โมฆะ (ม.155–156)
สำคัญผิดคุณสมบัติ/กลฉ้อฉล/ข่มขู่ → โมฆียะ (ม.157,159,164)
สำเร็จรูปเอาเปรียบเกินสมควร → เท่าที่เป็นธรรม (ข้อสัญญาฯ ม.4)
```
โมฆะให้สัตยาบันไม่ได้ (ม.172); ส่วนหนึ่งโมฆะอาจทำให้ทั้งหมดโมฆะเว้นแยกได้ (ม.173) ไม่ใช่ใส่ severability แล้วรักษาทุกกรณีได้ การนิ่งไม่แจ้งความจริงอาจเป็นฉ้อฉล (ม.162)

| กิจการ | แบบ/หลักฐานและผลขาด | ฐาน |
|---|---|---|
| ขายอสังหาฯ/เรือตั้งแต่5ตัน | หนังสือ+ทะเบียน มิฉะนั้นโมฆะ | ม.456 ว.1 |
| ขายสังหาฯตั้งแต่20,000บาท | หลักฐานลงชื่อฝ่ายต้องรับผิด/มัดจำ/ชำระบางส่วน; ขาดแล้วฟ้องไม่ได้ ไม่ใช่โมฆะ | ม.456 ว.2–3 |
| เช่าอสังหาฯ | หลักฐานลงชื่อ; เกิน3ปี/ตลอดชีวิตต้องหนังสือ+ทะเบียน มิฉะนั้นบังคับได้3ปี | ม.538 |
| กู้เกิน2,000บาท/ค้ำ | หลักฐานลงชื่อผู้ยืม/ผู้ค้ำ มิฉะนั้นฟ้องไม่ได้ | ม.653,680 ว.2 |
| อนุญาโตตุลาการ | หนังสือลงชื่อ/การโต้ตอบหรือวิธีที่กฎหมายรับรอง | พ.ร.บ.อนุญาโตตุลาการฯ ม.11 |
| licence TM/สิทธิบัตร | หนังสือ+ทะเบียน; โอนลิขสิทธิ์ใช้หนังสือลงชื่อสองฝ่าย ไม่ใช่ทะเบียน | โมดูล §4 |

## 2. เสนอ-สนองและตีความ

คำเสนอมีเวลารับถอนไม่ได้ในช่วงนั้น (ม.354); ไม่กำหนดเวลาแยกห่างกัน/เฉพาะหน้า (ม.355–356); สนองช้าหรือแก้ไขเป็นคำเสนอใหม่ (ม.359) ตรวจข้อยกเว้นส่งปกติแต่ถึงช้า ม.358 สัญญาห่างกันเกิดเมื่อสนองถึงผู้เสนอ หรือเกิดจากการกระทำเมื่อไม่ต้องสนอง (ม.361)

**ม.366–367 ต่างกัน:** มีข้อสงสัยเมื่อสาระสำคัญยังไม่ตกลง/กำหนดทำหนังสืออาจยังไม่เกิด; แต่สัญญาที่ถือว่ามีแล้วอาจยังสมบูรณ์หากจะทำแม้ไม่มีข้อที่ไม่ตกลง Term sheet ระบุแต่ละข้อผูกพัน/ไม่ผูกพัน ออนไลน์ ม.13/1 ของ พ.ร.บ.ธุรกรรมฯ คือข้อเสนอต่อสาธารณะ/ระบบอัตโนมัติ ไม่ใช่คำสั่งซื้อทุกชนิด; ม.13/2 รองรับสัญญาอัตโนมัติ

ตีความเจตนาแท้จริง (ม.171) → สุจริต/ประเพณี (ม.368) → สำเร็จรูปเป็นคุณแก่ฝ่ายไม่ร่าง (ข้อสัญญาฯ ม.4 ว.2) / คุณแก่ผู้ต้องเสีย (ม.11)

## 3. บริษัทและตราประทับ

นิติบุคคลทั่วไปแสดงความประสงค์ผ่านผู้แทนตามกฎหมาย/ข้อบังคับ/ตราสารจัดตั้ง (ป.พ.พ. ม.70) และใช้บทตัวแทนกับผู้แทน/บุคคลภายนอกอนุโลม (ม.77) จึงต้องตรวจฐานผู้แทน ไม่ใช้เงื่อนไขกรรมการบริษัทกับนิติบุคคลทุกชนิด

ตรวจหนังสือรับรอง DBD ล่าสุด จำนวนลงนามร่วม/เงื่อนไข ข้อบังคับและมติ: กรรมการจัดการตาม ม.1144 และใช้ตัวแทนกับบุคคลภายนอก ม.1167 ไม่เหมามติที่ประชุมใหญ่บังคับทุกธุรกรรม → `thai-corporate-secretarial`

**ตราไม่จำเป็นทุกบริษัท:** คู่มือ DBD ข้อ14 ให้ไม่จดตราได้ถ้าอำนาจไม่กำหนดประทับ ต้องทำตามเงื่อนไขจดจริง ไม่ใช้ตราแทนอำนาจ ม.9 ของ พ.ร.บ.ธุรกรรมฯ ใช้กับตราอิเล็กทรอนิกส์ด้วย

ต่างประเทศขอหลักฐานผู้ดำรงตำแหน่ง/มติ/POA และฐานะลงนาม; ตัวแทนตัวการซึ่งอยู่และมีภูมิลำเนาต่างประเทศรับผิดแต่ลำพังเว้นสัญญาแย้ง (ม.824) การรับรองลายมือชื่อไม่รักษาอำนาจที่ไม่มี

## 4. ตัวแทนและโอนสัญญา

- ตั้งชัดแจ้ง/ปริยาย (ม.797); แบบตามกิจการ (ม.798); อำนาจทั่วไปไม่รวมขาย/จำนองอสังหาฯ เช่าเกิน3ปี ให้ ประนีประนอม ฟ้อง อนุญาโตตุลาการ (ม.801)
- ห้ามทำกับตนเอง/เป็นสองฝ่ายเว้นยินยอม (ม.805); เชิด/ทำให้เชื่อโดยสมควรรับผิดต่อบุคคลภายนอกสุจริต (ม.821–822); เกินอำนาจไม่ผูกเว้นสัตยาบัน (ม.823)
- โอนสิทธิ: ห้ามโอนยกต่อสู้บุคคลภายนอกสุจริตไม่ได้ (ม.303); โอนเป็นหนังสือและแจ้ง/ยินยอมเป็นหนังสือเพื่อยกต่อสู้ลูกหนี้/ภายนอก (ม.306)
- **โอนภาระไม่ใช่โอนสิทธิ:** ใช้ยินยอมเจ้าหนี้/ข้อตกลงสามฝ่ายหรือแปลงหนี้ ม.349–351 (ข้อวิเคราะห์); แยกผลต่อประกัน จ้างแรงงานต้องยินยอม ม.577; จ้างทำของจ้างช่วงได้เว้นสาระอยู่ที่ความสามารถ แต่ยังรับผิด ม.607 ข้ออนุญาโตตุลาการผูกผู้รับโอนตาม พ.ร.บ.อนุญาโตตุลาการฯ ม.13

## 5. e-contract/e-sign

พ.ร.บ.ธุรกรรมฯ ม.7 ไม่ปฏิเสธผลเพียงเป็นอิเล็กทรอนิกส์; ม.8 หนังสือ; ม.11 พยาน; ม.13–14 เสนอ/สนอง/บอกกล่าว **ม.9 ต้องระบุตัว+เจตนา** และวิธีเหมาะเชื่อถือได้ หรือวิธีอื่นยืนยันได้เอง/ประกอบพยาน; ม.26 เป็นเกณฑ์ที่เชื่อถือได้ ไม่บังคับทุกสัญญาใช้ใบรับรองดิจิทัล

เก็บ version ที่แสดงก่อนยอมรับ เวลา ตัวบุคคล audit trail และส่ง/รับ คู่ฉบับเป็นข้อเจรจา ต้องตรวจอากรแยก (ป.รัษฎากร ม.110) e-sign ไม่แทนทะเบียน/อนุมัติ → `thai-tech-platform-law`

**ร่าง — ยังไม่มีผลใช้บังคับ:** ร่างธุรกรรมฯ ในรัฐสภาที่รับฟัง ส.ค.–ก.ย.2569 ไม่ใช้แทนกฎหมาย พ.ศ.2544 และฉบับแก้ไขแล้ว

## 6. อากรแสตมป์: ด่านก่อนใช้เอกสาร

เฉพาะตราสารในบัญชีท้าย (ป.รัษฎากร ม.104): เช่า(1) เช่าซื้อ(3) จ้างทำของ(4) กู้(5) POA(7) ค้ำ(17) จำนำ(18) ตัวแทน(21) คู่ฉบับ(23) ใบรับ(28) ซื้อขาย/licence/SaaS ไม่ปรากฏโดยชื่อ ต้องจัดประเภทเนื้อหา (ข้อวิเคราะห์) **อัตรา/วิธี/กำหนดยื่น → `thai-tax-international`**

ผู้เสียตามบัญชีเว้นตกลงเป็นอื่น (ม.107) จ้างทำของ=ผู้รับจ้าง ค้ำ=ผู้ค้ำ ทำนอกไทย: ผู้ทรงแรกในไทยเสียภายใน30วันนับได้รับ (ม.111) ลักษณะ4ยกเว้นเมื่อทำและปฏิบัตินอกไทย ล่าช้าตรวจ ม.113–117 ไม่ใช้ระยะขอแก้เป็นกำหนดปกติ

**ม.118 ไม่ปิดบริบูรณ์ใช้ต้นฉบับ/คู่ฉบับ/คู่ฉีก/สำเนาเป็นพยานคดีแพ่งไม่ได้จนเสียครบและขีดฆ่า** ไม่ใช่สัญญาโมฆะอัตโนมัติ e-stamp ตาม ม.8 ว.2 ของ พ.ร.บ.ธุรกรรมฯ ต้องวิธีที่หน่วยงานกำหนด ไม่ใช่ภาพแสตมป์บน PDF; เก็บหลักฐานชำระผูก version และตรวจ RD ฉบับปัจจุบัน

## 7. ภาษา กฎหมาย และศาล

ไม่มีบททั่วไปบังคับสัญญาธุรกิจเอกชนทุกฉบับเป็นไทย แต่ตรวจแบบเฉพาะเรื่อง ศาลใช้ไทยและสั่งแปลเอกสารต่างประเทศพร้อมคำรับรองได้ (ป.วิ.พ. ม.46) ภาษาเป็นหลักระหว่างคู่สัญญาไม่ตัดอำนาจศาล; หน่วยงานอื่นตรวจข้อกำหนดเอง เอกสารหลายภาษาที่มีภาษาไทยด้วย หากข้อความต่างกันและหยั่งทราบเจตนาไม่ได้ว่าจะใช้ภาษาใดบังคับ ให้ถือตามภาษาไทย (ป.พ.พ. ม.14) จึงต้องเขียนฉบับหลักให้ชัด ไม่ปล่อยให้ตกบทนี้โดยไม่ตั้งใจ

พ.ร.บ.ขัดกันฯ ม.13: เจตนา → สัญชาติร่วม → ถิ่นทำ (ห่างกัน=ถิ่นสนองถึง; ไม่ทราบ=ถิ่นปฏิบัติ); ม.9 แบบ; ม.5 ความสงบเรียบร้อย; ม.8 พิสูจน์กฎหมายต่างประเทศ ข้อศาลไม่สร้างเขตอำนาจที่กฎหมายไม่มี (ป.วิ.พ. ม.2,4) ไม่ซ้อนศาล/อนุญาโตตุลาการโดยไร้ลำดับ แบบ IP/UCTA/แรงงาน/PDPA ต้องตรวจขอบเขต ไม่เหมาว่าบทไทยทุกฉบับใช้เสมอ → `thai-international-disputes`

## 8. นิติกรณ์/Apostille

HCCH ยืนยันไทยภาคยานุวัติ30มิ.ย.2569 มีผล28ก.พ.2570 ณ วันที่ข้อมูลนี้ยังไม่ใช้ Apostille แทนกระบวนการไทย ตรวจเอกสาร ประเทศ และผู้รับกับกรมการกงสุล/สถานทูต เอกชนอาจต้องรับรองลายมือชื่อก่อนนิติกรณ์ เอกสารต่างประเทศอาจผ่านต้นทาง+สถานทูตไทย ไม่ใช้ห่วงโซ่เดียวกับทุกกรณี นิติกรณ์ไม่รับรองเนื้อหาสัญญา

## 9. ผิดนัด ค่าเสียหาย และเลิก

- ถึงกำหนด/เตือน (ม.204) กำหนดปฏิทินชัดอาจไม่ต้องเตือน; เหตุไม่ต้องรับผิดไม่ผิดนัด (ม.205)
- ไม่ชำระตามมูลหนี้ (ม.215); เสียหายปกติ/พิเศษที่คาดเห็นหรือควรคาดเห็น (ม.222); ความผิดผู้เสียหาย/ไม่บรรเทา (ม.223) ไม่ใช้ indirect/consequential แทนกฎหมายไทย
- ดอกเบี้ยตัวบทตรวจ: ม.7=3% เมื่อมีหน้าที่แต่ไม่กำหนด; ม.224=ม.7+2% เว้นฐานชอบให้สูงกว่า ห้ามซ้อนดอกผิดนัด; ม.224/1 เฉพาะต้นงวดผิดนัด พ.ร.ก.2564มีผล11เม.ย.2564พร้อมบทเฉพาะกาล อัตรา ม.7 ปรับด้วยพระราชกฤษฎีกาได้ ตรวจวันคำนวณ ไม่รับรอง5%ทุกหนี้
- เหตุสุดวิสัย ม.8 ป้องกันไม่ได้แม้ระวังสมควร; พ้นวิสัยไม่รับผิด ม.219/ผลตอบแทน ม.372 ต่างจากล่าช้าชั่วคราว ต้นทุนเพิ่ม หรือคลาวด์ล่มทั่วไป
- เลิกโดยแสดงเจตนา (ม.386); เตือน+เวลาพอสมควร (ม.387) ต่างจากเวลาเป็นสาระ (ม.388)/พ้นวิสัยเพราะลูกหนี้ (ม.389); คืนฐานะเดิม/ไม่กระทบค่าเสียหาย (ม.391); หลายฝ่าย (ม.390); การกำหนดเวลาใช้/เสียสิทธิ (ม.393–394)

ทำ claim matrix ก่อนส่งคำฟ้อง อายุความ → `thai-litigation-deadlines` ไม่เลือกวันฟ้องจากระยะ warranty อย่างเดียว
